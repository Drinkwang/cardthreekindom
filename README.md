# 《拍案三国》Godot 工程

**引擎：Godot 4.7.2**　**状态：v0.9 可玩骨架（武将练级 + 被动 / 装备五部位 / 全屏城建；代码占位美术）**

三国题材**增量拍卡 + Roguelite 多局刷 + 放置挂机**游戏。
**主界面就是一张桌子**：敌人牌正面朝上、歪着散开，你用鼠标去拍。
单击 = 轻拍（1 耐力）；按住划过 = 重拍（×2.5，每张 2 耐力，可一次扫过多张）。拍翻的牌归你。

**v0.9 把三套养成做成真系统**（v0.8 时它们还是"有名字、没接线"）：
**武将练级**（每将独立等级，战力 ×(1+8%×Lv)）、**武将被动真正接入战斗**
（卡面 `effect` 文案 → 20 类规范词条）、**装备巢**（兵器/铠甲/坐骑/兵书/宝物，依次解锁）、
**建筑强化（Lv.10）与建筑合成**、**全屏「城建」界面**（城池列表 / 槽位网格 / 产出总览 + 合成）。
关键是**一个 effect 解析器同时喂「武将被动」和「装备属性」**，93 条卡面文案无需重写。

**v1.1 装备 / 技能树 / 带兵（2026-09-26 用户纠错后重做）**：
- **装备巢改成「每个武将各自一套」**（原来是全局共用 5 格）。一件装备同时只挂一个将，挂给别人＝自动转过去。
- **装备卡不再上桌** —— 敌人池里一件装备都没有，唯一来源是**买卡包开出**。
- **士兵没有装备巢**，但**可以当武将出战**；点亮技能树「武将带兵」后，士卒能挂到武将麾下
  （**不占携带位、战力全额计入**）。
- 升级树正式变成**技能树**：3 层（一·立身 / 二·扬名 / 三·成军）+ **浅前置**（前置点亮过一次即放行，不卡等级）。

**v0.8 系统层**：roguelite「局内刷 + 局外升级」——**开局极弱 → 结算金币 → 回大本营升级 → 再来一趟**；
全屏**大本营**（技能树 / 出征 / 上阵+每将装备巢与兵位 / 城建入口）、**耐力由玩家等级驱动**、
**上阵携带位（初始 3，上限 6）**；拍完前几桌才解锁城池与挂机。

**v0.7 表现层**：全屏**荆州舆图**（真实经纬度绘制 + 节点松弛）与**开包翻牌特效**（逐张翻转 + 高星特写）。

**S5 美术层（2026-09-26）**：整套界面换成**「90 年代怀旧印刷」**——旧木课桌 / 旧纸舆图 / **印刷网点卡框**（六档星级各一色）/
纸上的墨字。做法是**混合管线**：不透明大图交给 AI 出图，凡是要 alpha 的（卡框、纸面板、按钮、卡背圆角）
一律**程序化生成**。见第四节之二。风格基准与取舍见上级目录 `美术重制清单.md`。

策划案见上级目录 `策划案.md`（v0.9），卡池见 `卡池表.xlsx`。

## 一、跑起来

本机 Godot 4.7.2 在 `~/Downloads/Godot.app`（另有 `/Applications/Godot.app` 是 4.3，别用错）。

**用编辑器打开**

```bash
open -a "$HOME/Downloads/Godot.app" --args --path "$PWD"
# 或：双击 Godot 4.7.2 → 导入 → 选这个 game 目录 → 打开 project.godot
```

**直接玩（有窗口）**

```bash
"$HOME/Downloads/Godot.app/Contents/MacOS/Godot" --path game
```

**无头自检（不开窗口，验证核心循环 + 桌面输入管线 + 舆图/翻牌 + v0.8 局外养成 + v0.9 三套养成 + v1.0 底部上阵条 + v1.1 装备巢/技能树/带兵，257 项断言）**

```bash
cd game
"$HOME/Downloads/Godot.app/Contents/MacOS/Godot" --headless --path . tests/SelfTest.tscn
```

> ⚠️ 新增了 `class_name` 脚本（PaanMapView / PaanReveal / PaanHome / PaanCity）后，第一次跑之前先 `--import` 一次，
> 让 Godot 重建全局类缓存；否则会报 "Could not find type"。
> ⚠️ 实测：**改过 `.gd` 之后跑截图前也建议先 `--import`** —— 2026-09-26 再次遇到没加新类也报
> "Could not find type PaanHome"。反正 `--import` 只要几秒，写进固定流程最省事。
>
> ⚠️⚠️ **重跑了 `tools/gen_s5_print.py` / `prepare_s5_assets.py` 之后也必须先 `--import`。**
> 普通运行（`--path .`）**不会重新导入改动过的 PNG**，它继续吃 `.godot/imported` 里的旧贴图 ——
> 于是你会对着旧画面反复改代码，怎么改都不动（2026-09-26 在这上面浪费了一轮）。
> 改完素材的固定流程：`--import` → 再截图。
>
> ```bash
> "$HOME/Downloads/Godot.app/Contents/MacOS/Godot" --headless --path . --import
> ```

**渲染截图（开窗口跑完自动退出，把画面存成 PNG）**

```bash
G="$HOME/Downloads/Godot.app/Contents/MacOS/Godot"
"$G" --path . tests/Screenshot.tscn -- --out=/tmp/paan.png            # 开局桌面
"$G" --path . tests/Screenshot.tscn -- --out=/tmp/full.png --region=16  # 指定区域铺满桌
"$G" --path . tests/Screenshot.tscn -- --out=/tmp/drag.png --drag=150,300,1150,300  # 拖拽重拍瞬间
"$G" --path . tests/Screenshot.tscn -- --out=/tmp/map.png --map --demo  # 全屏荆州舆图（伪造中期存档）
"$G" --path . tests/Screenshot.tscn -- --out=/tmp/home.png --home --mid # 全屏大本营（伪造中期养成存档）
"$G" --path . tests/Screenshot.tscn -- --out=/tmp/city.png --city       # 全屏城建（伪造中期存档，含建筑等级）
"$G" --path . tests/Screenshot.tscn -- --out=/tmp/clear.png --clear     # 拍完整桌 → 舆图自动弹出
"$G" --path . tests/Screenshot.tscn -- --out=/tmp/pack.png --demo --pack=0   # 开卡包翻牌特效
"$G" --path . tests/Screenshot.tscn -- --out=/tmp/hi.png --demo --reveal=E12,G13,E26,G10 --instant --full  # 高星特写
"$G" --path . tests/Screenshot.tscn -- --out=/tmp/pool.png --region=2 --pool   # 展开底部「卡池」条
"$G" --path . tests/Screenshot.tscn -- --out=/tmp/dep.png --region=2 --deploy=G26  # 真实鼠标事件拖一张牌上阵
"$G" --path . tests/Screenshot.tscn -- --out=/tmp/bar.png --table --pool   # 桌面 + 上阵条（每个将标出「装N 兵N」）
```

截图工具参数：`--out=` `--region=N` `--drag=x1,y1,x2,y2` `--map` `--home` `--city` `--mid` `--table` `--demo` `--clear` `--fresh`
`--drawer=1` `--pack=N` `--reveal=ID,ID,...` `--instant` `--full` `--dump` `--menu` `--rules` `--pool` `--deploy=卡id`

> `--mid` / `--home` / `--city` / `--table` 会伪造一个"中期局外成长"存档（前 4 处已克服、技能树点了一些、
> 上阵 5 个武将且练到 Lv.3、**每个将各自装了 2 件装备 + 2 个兵**、城建有建筑且升过级），用来截"玩家玩了一阵子"的画面。
> `--table` = 只要中期存档、**不打开大本营**（看桌面 + 底部上阵条）。
> `--dump` 打印关键节点尺寸，排查布局问题用。
> `--pool` / `--deploy=` 验证底部上阵条：`--pool` 只展开卡池，`--deploy=` 会**用真实鼠标事件**
> 把卡池里某张牌拖到第 1 个携带位，并在日志里打印 `[deploy] 拖前/拖后 carry=...`。
> ⚠️ 这两个必须**非无头**跑：无头模式下视口根本不派发 GUI 输入事件（实测连 `_gui_input` 都收不到），
> `push_input()` 和 `Input.parse_input_event()` 都推不动 Godot 的拖放。自检则相反，只跑无头。
> 建议把 `Godot.app` 从 Downloads 挪到 `/Applications`，避免被清理掉。
> 挪完记得同步改 `~/.workbuddy/mcp.json` 里的 `GODOT_PATH`。

## 三、目录结构

```
game/
├── project.godot              工程配置（autoload: GameData / GameState）
├── data/                      由 tools/export_game_data.py 导出的运行时数据
│   ├── cards.json             169 张卡（含 power / equip_pct / subtype / effect 字段）
│   ├── regions.json           21 区域（含 unlocks / unlocked_by + lon/lat/mx/my 舆图坐标）
│   ├── enemies.json           每区域的具体敌人与血量（合计 == 区域总血量）
│   ├── routes.json            四条路线
│   ├── packs.json             9 个卡包
│   └── buildings.json         30 张建筑（产出 / 功能）
├── scenes/Main.tscn           桌面主场景（Control 根 + main.gd）
├── scenes/MainMenu.tscn       主菜单场景（run/main_scene 指向这里）
├── scripts/
│   ├── main_menu.gd           主菜单（开始游戏 / 玩法说明覆盖层 / 退出）
│   ├── main.gd                桌面拍卡界面 + 四个全屏覆盖层（舆图/大本营/城建/翻牌）接线 + **底部上阵条/卡池拖拽**（全代码构建）
│   ├── home_view.gd           PaanHome —— 全屏大本营（技能树 3 层 / 出征 / 上阵+练级+**每将装备巢与兵位** / 城建入口）
```

## 四之二、美术管线（S5「90 年代怀旧印刷」）

### 4.1 为什么是混合管线

生图接口**不支持透明底**（实测 `background:"transparent"` 被静默忽略，返回永远是 `mode=RGB`）。
所以分两路：

| 路 | 用途 | 工具 | 产出 |
| --- | --- | --- | --- |
| **AI 出图**（不透明全幅大图） | 牌桌 / 大本营书桌 / 城建古城图 / 舆图底图 / 纸纹理 / 卡背 | `tools/gen_s5_kit.py` → `tools/prepare_s5_assets.py` | `assets/bg/*.png` `assets/tex/*.png` `assets/cards/cardback.png` |
| **程序化生成**（需要 alpha 的一切） | 卡框 6 档 / 卡面 / 纸面板 / 按钮 4 态 / 印刷叠加层 | `tools/gen_s5_print.py` | `assets/ui/*.png` |

程序化这一路不只是"没办法的办法"，它对印刷风反而更对：**网点、错版、磨边、边框几何都可以像素级复现**，
而且没有 AI 的一致性抖动。

### 4.2 两条硬规则（都是踩出来的）

**① 九宫格没有 `texture_scale`，所以「文件里的边框宽度 = 屏幕上的边框宽度」。**
Godot 4 的 `StyleBoxTexture` 没有缩放属性，九宫格的角是按源纹理 **1:1** 画的。
想让边框变细只能**重新生成一张对应尺寸的纹理**，不能在运行时缩放。
`main.gd` 里 `set_texture_margin_all()` 的值必须**等于源图上的真实边框宽度**：

| 资源 | 源尺寸 | 边框 | 对应常量 |
| --- | --- | --- | --- |
| `ui/cardface_*.png` | 128×176 | 16 | `main.gd FRAME_MARGIN` |
| `ui/panel.png` | 112×112 | 14 | `PANEL_MARGIN`（main / home / city 各一份） |
| `ui/btn_*.png` | 40×40 | 6 | `BTN_MARGIN` |

**② 会被拉伸的九宫格，中心必须接近纯色、四条边必须沿长边均匀。**
九宫格的中心与边是**直接放大**的。所以：
- **不能裁 AI 纸纹理**当中心 —— 84×84 放大 6 倍会变成一大片彩斑；
- **不能用网点屏 / 磨边 / 错版**做边 —— 沿长边会被拉成彩条。

正确写法是**只用「到边缘的距离 `d`」决定颜色**（同心矩形环），这样四边天然均匀。
`make_panel()` / `make_button()` 都按这个约束写，注释里有说明。
（`make_frame` / `make_cardface` 不受此限：卡框是接近 1:1 使用，甚至可以放细节。）
