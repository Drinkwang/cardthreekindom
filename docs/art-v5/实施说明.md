# 《拍案三国》构筑与基建美术实施 · v1.5

日期：2026-10-05。根据用户批准的四区大本营和「升级·修炼图」参考，新增两张插画并重做构筑、基建的实际操作页；六名武将接入三组可混搭联动。

## 1. 美术与入口

延续木桌、旧纸、墨线、朱印和低饱和靛蓝、玉绿。插画不烘焙操作文字，实际界面负责显示名称、金币、状态与按钮。

- `assets/art_v5/deck_scene.png`：将牌、兵牌、红纸牌盒与兵书。
- `assets/art_v5/base_scene.png`：纸上城池，包含粮仓、工坊、练兵场、城门和建设图纸。
- `assets/art_v5/generation.json`：内置 ImageGen 的完整提示词和参考来源。
- `docs/art-v5/index.html`：新插画与真实游戏截图的浏览页。

生成采用内置 ImageGen，以两张用户图片作为风格参考，分别生成新的生产插画。保留原始图片，未额外裁切或改画。原有武将卡面继续用于实际选将，避免插画中的装饰将牌与真实选项混淆。

## 2. 构筑页

上方为当前携带位，初始三位、上限六位，主角常驻。点击阵位或仓库卡格查看武将；点击空位可以回到选将区。

左侧仅聚焦当前所选卡：卡面、等级、战力、已有被动、该将的实际联动能力，以及培养/上阵/卸下。培养扣金币、卸下保留持有卡。未上阵的武将不触发联动。

右侧分为将牌组合、武将装备、武将带兵三个页签。组合页显示已经组成的链条、缺少的搭档，以及可按雷印/烈火/追击/士兵筛选和按名字、能力搜索的仓库。筛选不会清除当前选择；金币刷新只更新数字和可购买状态。

装备仍是每将独立的兵器、铠甲、坐骑、兵书、宝物。换装和卸装返仓；把同一装备分配给另一将会转移，不能复制。士兵可上阵，也可在解锁兵位后挂到武将麾下；已派出的士兵不会重复上阵。

## 3. 六将与三个联动

以下倍率均以当前轻拍基础伤害 B 为参照，沿用已有武将、装备和培养的数值体系。主动输入仍是玩家轻拍/重拍；武将按拍击事件自动接招。

| 路线 | 武将 | 实际效果 | 操作重点 |
|---|---|---|---|
| 雷印 | 朱灵 | 每3次基础拍击，给存活最厚牌附1层雷印，最多3层 | 用轻拍或重拍积印 |
| 雷印 | 文聘 | 重拍消耗目标最多2层雷印，每层追加1.5B伤害；冷却6秒 | 对带印目标重拍 |
| 烈火 | 韩玄 | 重拍点燃存活目标6秒，每秒0.3B；点火冷却4秒 | 先点厚牌，再拍其他牌 |
| 烈火 | 程普 | 每4次基础拍击，复制已有燃烧给另一张未燃烧牌，保留伤害与剩余时长 | 维持拍击，扩散燃烧 |
| 追击 | 周仓 | 每3次轻拍，标记存活最厚牌6秒；基础拍击对标记牌增伤20% | 轻拍起手，再集中攻击 |
| 追击 | 马良 | 标记牌翻倒时，向另一张最低生命普通牌追击1B；冷却6秒 | 翻标记牌、连带清残牌 |

三组可以混搭，没有职业锁。只有一位搭档时仍能使用其独立效果，组合提示会说明缺少哪位搭档。雷印、燃烧和标记在桌面有状态文字；联动触发有对应颜色的浮字。追击不选守将，燃烧和追击的派生伤害不再次累计基础拍击次数，避免无限循环。

新桌与结算清除本局状态；派生伤害按实际扣血计入结算，一张牌只发放一次翻牌收益。沿用原来的存档方式：持久成长保存，重新启动后局内桌面重铺。

## 4. 基建页

左侧是已克服城池的城册；中间是城池经营插画、当前城池收益、槽位及所选建筑；右侧切换建筑仓库和建筑合成，不同时展开两份长列表。

- 建造：选择城池，在仓库使用真实建筑卡，放入下一格空槽。
- 升级：选择已放建筑，按显示的金币价格强化，更新该城与全城收益。
- 拆除：返还建筑卡，沿用现有规则，建筑强化等级重置。
- 合成：三张同星建筑加金币，获得随机高一星建筑。
- 未解锁时显示解锁要求；无建筑时显示空槽和仓库提示；后期多槽仍可滚动选择。

实时金币增加时保留当前城池、建筑槽、页签和滚动位置，避免挂机产出反复重建整页。

## 5. 战后流程

大本营的商店、构筑、升级、基建四区继续保留。构筑和基建页面底部也保留最近战果：未通关可直接重新挑战原关或换地图，通关可进入大地图。培养、换装、派兵、建设和返回操作不会修改既得战果；重新挑战重铺敌方卡牌，不重复结算前一桌奖励。

本轮完成两页美术、真实整备操作和六将联动。自动拍、自动下一关与新的挂机升级路线仍在后续策划范围。
