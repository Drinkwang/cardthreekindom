## 本轮视觉方向

把先前的古代桌面氛围接回“童年拍卡、操场就是荆州”的故事。米色旧纸、低饱和朱红、墨线、楷体题签与深木桌构成统一视觉。插画只承载场景和人物，卡名、星级、血量、按钮与说明仍由游戏实时绘制。

### 封面与场景

新封面表现小野与短发唐棠在操场木桌前玩纸牌；左侧纸页集中标题和入口，右侧保留人物。原有继续、另启新局、确认、说明和退出功能保持有效。

新桌面采用俯视旧木板，中央留空，纸包、粉笔、地图和旧盒集中在边角。游戏叠加轻薄暖墨，以突出牌面；开包页也使用同一木桌。

### 卡面、顶栏与携带栏

- 顶栏整理为单行，资源分列，舆图、大本营、城建、卡铺配上印刷式小图标。
- 桌牌放大人物区域，阵营小印、名字与星级置于上方，细血条和血量置于底部；主桌加小题签。
- 纸框添加双墨线、纸纹与少量磨损；颜色保持克制，文字区域留清晰底色。
- 携带栏加宽，头像单独取插画上部，避免横向裁切头顶；空位用虚线纸框。保留卡池、拖拽、装备与带兵信息。
- 连续拍击先终止旧震动，再以固定铺牌位置继续，避免位置累积偏移。

### 整备、城建、地图与揭牌

大本营改为“练拍手册 / 下一张课桌 / 我的将牌”纸页；城建使用“荆州城册 / 铺城经营 / 城中账簿”。大面积灰蓝底色改为浅暖纸，阵营色集中到小印章。两页修正覆盖层的尺寸约束，底部说明在 800 和 720 高窗口均完整显示。

地图加入细双框与指北标记，移除遮挡北部节点的常驻浮框。悬停提示靠边显示，详细战报保留在右栏；最南节点的名称移到上方，避免触碰下边框。

揭牌改用暖墨、印痕与短线点缀。轻拍、重拍增加墨点、纸屑与掌风，已有“拍案！”触发三道金赭墨线；伤害文字先停留 0.15 秒再淡出，便于读数。特效仅呈现实际攻击，不追加伤害，也不表示策划中的其他招式已实装。

## 与策划案的关系

本轮实装的是视觉和交互表现。童年抢卡、老婆婆买包、完整八章剧情、12 招、四流派及自动训练仍以[剧情与放置策划案](../拍案三国_操场荆州剧情与放置策划案.md)为目标设计稿，尚未据此开发。现有城建离线收益继续有效，不能等同于自动拍击系统。

本轮没有修改卡池数据、经济数值和战斗规则。短发唐棠的新形象已经接入 G56，未来剧情解锁条件与伙伴定位仍按策划案实施。
