## 统一范围

- 外框与页面资源栏使用暖黑玄漆、分层金边，深底标题为浅象牙色，统计和次级文字为低饱和暖金色；返回、继续和开卡操作采用同套漆面按钮。
- 休息页头保留金边、不铺卷云，避免装饰干扰资源统计；战果和舆图底栏继续使用低对比卷云，装饰不接收鼠标或键盘焦点。
- 营地四格插画、构筑将牌册、技能修炼图及详情、商店货架、基建内容、舆图内容和开卡牌面均保留纸面与深墨正文。构筑透明根节点下增加无额外内边距的纸面托底，防止黑字落在漆底。
- 开卡层保留原翻转、全部翻开与收好卡牌流程；外沿为玄漆金框，标题、说明和卡牌内容仍在纸面上，不把原深色遮罩上的浅字直接搬到浅纸底。
