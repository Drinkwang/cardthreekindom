# v2.5 UI 表现强化实施说明

本轮根据用户明确的 UI 强化要求，将已确认效果图中的古典界面语言实装到主 HUD、升级页、上阵栏、小地图和营地窗口。重点是信息层级、纸框质感、按钮反馈与升级状态的可读性。

## 界面变化

- 主 HUD：黑墨题匾配朱砂印章，城名使用独立纸签；铜钱图标配大字号金币数字，倒计时独立分组，朱砂按钮直达升级。
- 统一皮肤：纸纹、墨金双框、角饰与投影贯穿主界面、相机控件、营地外框和操作按钮；按钮区分正常、悬停、按压、禁用与焦点状态。
- 上阵栏：保持紧凑高度，卡槽增加纸框、角饰与悬停表现，卡池入口统一皮肤。
- 升级页：拍力、拍速、范围、时长四卡使用插画、等级签、收益纸券与购买按钮分区；清楚区分当前选中、可升级、金币不足、待解锁和满级。当前值、升级后值、收益和价格分别展示。
- 营地：统一标题、外框与继续拍击按钮，升级页移除底部重复的“去升级”入口。
- 小地图：题签、朱砂图印、双框和折叠入口反馈更清晰。展开 220×185、收起 86×34，位置仍在右上角；原有 M 键、标题与按钮收放、点击或拖动定位行为保留。

## 素材与实施

本轮没有生新图，复用既有升级插画、铜钱图标及 `assets/art_v3` 纸纹，边框、角饰与印章由代码绘制。背景图片与战斗数值保持当前实现，包括拍击伤害、冷却、金币收益和升级价格。

统一皮肤由 `scripts/ui/ui_skin.gd` 提供，纸框装饰由 `scripts/ui/paper_chrome.gd` 绘制；小地图使用 `scripts/ui/city_minimap.gd`。主界面、升级页和营地接入同一套样式。
