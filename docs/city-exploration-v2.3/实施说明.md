# v2.3 城池巡游与可收起小地图

日期：2026-10-09。引擎：Godot 4.7.1。

按用户确认的城池探索方案实施：将牌散在整座城池里，保留间距；鼠标滚轮缩放，靠近场地边缘移动镜头，右上角增加可收起小地图。

## 本轮交互

| 操作 | 行为 |
| --- | --- |
| 左键单击 | 立即拍击光标圆圈覆盖的存活牌，计一掌、共用冷却，金币即时入账 |
| 滚轮 | 以鼠标所在位置为锚放大或缩小镜头 |
| 鼠标靠近场地边缘 | 持续向该方向移动镜头，查看其他街区；靠近角落可斜向移动 |
| 点击或拖动小地图 | 镜头移到对应的城内位置 |
| 点击小地图标题／收起按钮，或按 M | 收起、展开小地图；收起时保留“地图 M”入口 |
| 全城按钮 | 恢复100%完整城池视野 |
| 中键拖动 | 保留为辅助平移方式 |

默认镜头为180%，从北部街区起步。全城基准尺寸2400×1500；卡牌106×146，随镜头一起缩放。卡牌较多时场地随布局扩大，避免把牌塞回小范围。

镜头改变显示比例，实际世界中的拍击范围保持不变。范围升级仍从半径34开始，每级增加6；金币、拍速、拍力与轮时长等原规则沿用。

## 地图与输入

小地图固定在场地右上角，展开尺寸220×185，收起为86×34的入口。朱红点对应全城存活牌，青绿色框对应当前视野；牌翻起后从小地图中移除。主场地与小地图共用 `assets/art_v11/city_world.png`，牌点和视野框均从真实世界坐标计算。

鼠标在小地图或缩放栏上操作时，输入由相应控件接收，避免误拍场地上的卡牌。打开整备、剧情等覆盖层时，停止场地镜头与拍击输入；鼠标移出场地、窗口失焦时停止边缘移动。

## 小地图方案比较

| 方案 | 优点 | 本项目的取舍 |
| --- | --- | --- |
| **右上角可收起，本轮采用** | 随时查看牌点与视野，收起后保留入口 | 底部已有上阵条，右上角更适合放地图；不会挤占卡池空间 |
| 右下角常驻 | 地图与底部操作区集中 | 会挤占上阵条与卡池空间，较矮窗口更拥挤 |
| 全屏／半透明地图 | 适合查看整个城池与路线 | 覆盖范围大，持续打开会遮挡限时拍牌，适合临时查看 |

右上角推荐来自本项目布局判断。[小地图位置案例研究，第4页](https://www.galaydegames.com/uploads/6/2/8/0/62800289/minimapstudy.pdf)列举了右上角与右下角等已有游戏方案；该研究样本较小，不用来证明哪个角落普遍更好。[Factorio 开发日志](https://www.factorio.com/blog/post/fff-405)说明了从覆盖整个画面的界面改为地图旁面板，以保留正常地图操作的做法。

## 生成素材与实机画面

新城池由内置 `image_gen.imagegen` 生成：

- 运行时素材：`assets/art_v11/city_world.png`。
- 完整提示词及路径：`assets/art_v11/generation.json`。
- 主场地采用俯视城池，装饰建筑与河道沿边布置，内部空地用于实时卡牌。
- 卡牌、光标、小地图牌点和视野框不烘焙进背景，由游戏绘制。

[实机画面册](index.html)可全宽切换查看：

| 文件 | 展示内容 |
| --- | --- |
| `play-expanded.png` | 180%默认视野，右上角小地图展开 |
| `play-collapsed.png` | 小地图收起，右上角保留地图 M 入口 |
| `play-east.png` | 移动到另一街区，小地图视野框同步移动 |
| `play-720.png` | 1280×720窗口布局 |

四张画面已通过实际渲染与目视检查，展开和收起采用同一镜头。800、720高度下地图与缩放栏完整可见。另一街区通过真实GUI单击拍中一张牌，产生1.9伤害和0.855金币；小地图视野框与场景一致。

实际GUI输入另验证了M键、标题、按钮收放，点击地图定位，以及在地图上滚动不会缩放场景或误拍，六项均通过，见[minimap-gui.log](minimap-gui.log)。
