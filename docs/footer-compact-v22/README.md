# 底栏压缩 v22

2026-10-19。用户确认压缩的是整个底部栏，不只是把右下小地图变矮。

此为历史版本。2026-10-21继续压缩并去掉标题，当前规格见[底栏压缩v23](../footer-compact-v23/README.md)。

## 改动范围

- 小地图220×148改为220×124，并在底栏内向下对齐。标题统一为“地图”，不再输入城池名或拼接“全图”。
- 题签带收紧4像素，地图内容区域仍有85像素高度；等比显示、世界坐标往返、点击与拖动导航保持原逻辑。
- 底栏由约164像素压到140像素，主地图多出24像素；保留底部16像素滚屏安全区，不挤压窗口边缘导航。
- 上阵卡牌最低88像素、卡槽滚动区112像素、字体及旗子尺寸均不变，不靠缩小卡牌腾空间；超出卡位仍横向滚动。
- 不改背景美术、主地图世界尺寸、默认镜头目标、牌位、战斗收益或存档。

压缩后的12区小地图曾出现题签遮住红点：坐标与点位数量测试通过，但真实画面不可读。现当分区格高不足28像素或宽不足42像素时不画文字题签，只保留边界、红点与视野框；5区仍显示题签，主地图分区信息不改。原生720/800窗口需要复核点位，不能只改尺寸断言就宣称完成视觉验证。

验证使用`--test-profile`隔离档并串行运行；日志与真实窗口截图在`docs/shots/footer-v22/`，沿用项目截图忽略规则。验证范围与最终结果见[存档兼容与验证](../../游戏策划/10_存档兼容与验证.md)。
