# 连续城坊渲染

本轮用连续地面、全城道路与透明局部景物替代旧全城底图和矩形分区插画叠放。道路先统一绘边缘、再统一铺路面，交叉口不残留分区边框；地面纹理、道路宽度与景物大小都使用世界坐标。5区和12区使用相同尺寸的建筑，不根据城池总尺寸拉伸。

`scripts/ui/district_art.gd` 继续由主地图和小地图共用。没有修改分区数量、矩形、世界尺寸、牌位、判定、区号、征服状态或存档结构。景物按完整透明轮廓绘制，不裁成分区矩形；中心牌阵保持安静，外围树丛与城内使用同一图集。

新增图集位于 `assets/art_v15/city_scenery_atlas.png`，内置 image_gen 生成，1536×1024，RGBA。3列2行依次为坊市、军营、园林、树丛、石草、摊位，每格512×512；运行时直接采样图集，不修改或重新抠图。完整提示词见同目录 `generation.json`。
