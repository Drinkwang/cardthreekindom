此页为历史方案；当前已由[开放平地v21](../open-field-v21/README.md)替代，不再绘制这里记录的逐区建筑。

2026-10-18。采用用户选定的手绘动画风：清晰屋瓦、柔和石材与低对比地面，减少裂纹、污渍、碎草、落叶和零散杂物。中间牌阵留空，地标集中在牌阵上下的安全空隙。UI布局、人物卡和RTS操作不改。

## 实际实现

- `assets/art_v17/terrain_ground_atlas.png`：2172×724，3列1行；暖灰石板、浅赭土坪、青灰石板。
- `assets/art_v17/terrain_edge_atlas.png`：1536×1024，2列3行；瓦屋银杏、城关、庭殿、码头、竹石、田舍。
- `scripts/ui/city_terrain_profiles.gd`：21城独立配置地表、主副地标、布局与偏移。首区的实际地表及主副地标左右组合均不同，不只换城名或色调。
- `scripts/ui/district_art.gd`：地面按世界坐标镜像铺排；每格纹理在运行时独立缓存并各自生成mipmap，避免整图缩小串色；边景使用明确安全源框，清除邻格残片。
- 主地图与小地图传入同一实际城池编号，共用同一绘制。边景不进入牌阵保守外包围框及32世界单位安全距，不修改原分区与牌位。

这里只是**3类地表、6组地标组成的21套城市配置**，不是21张独占手绘整城背景。石板仍有可见重复节奏；同城各分区沿用该城地标组合，不是每区独占建筑。城市主题为游戏美术设定，不宣称历史地理复原。
