# 四区大本营实施说明 · v1.4

日期：2026-10-05。根据用户批准的战后四区参考图实施，第四区由地图改为基建。

## 已接入游戏

主页采用旧木桌、米黄纸面、朱红框线和四幅怀旧印刷插画。入口固定为商店、构筑、升级、基建；战果与继续操作放在底部，不再把升级树、关卡详情和将牌列表同时堆在首页。

| 入口 | 实际功能 |
| --- | --- |
| 商店 | 全屏奶奶卡铺，卡包购买、招降、合成、图鉴；沿用原卡池和价格规则 |
| 构筑 | 将兵上阵、武将升级、每将独立装备、武将带兵；分为上阵、装备、兵种页签 |
| 升级 | 原技能树和前置条件，包含耐力、拍力、携带位及后续能力 |
| 基建 | 原城池建筑系统，放置、强化、合成和挂机收入；未解锁时可进入查看条件 |

## 战后与继续

通关和未通关都先进入同一张大本营。四区始终可用，允许先升级、换构筑、买包或经营，再决定下一步。

| 状态 | 底部操作 | 行为 |
| --- | --- | --- |
| 已通关 | 进入大地图 | 玩家点击后才开地图，优先定位相邻已解锁目标，不自动开战 |
| 未通关 | 重新挑战 / 换地图 | 原关重试；或开地图定位原关，再选其他已解锁目标 |
| 战斗中手动回营 | 继续拍卡 | 恢复当前桌面，保留剩余敌牌血量和耐力 |

重试使用最新成长、武将、装备和兵种，按当前上限补满耐力；敌牌满血重铺，局内连击与计数清零。永久成长、牌库和已获得金币保留。

最近战果记录本趟击倒、伤害与战斗获金，包含击倒奖励及结算或首通奖金。进入整备页、购物或升级不会覆盖这条战果；重试不会再次发放旧奖励。

商店、基建、地图均提供回营路径。升级和构筑属于营地内部子页，返回恢复原战果。成长、基建和最近战果自动保存；战后继续游戏回到大本营。旧存档无有效战果时沿用原加载行为。

## 验证范围

使用 Godot 4.7.1，先导入资源，再运行原玩法、美术布局、战果状态和四区界面联动验证。截图使用独立测试档，正式进度保留。

| 验证 | 结果 |
| --- | --- |
| SelfTest 原玩法 | 259 项通过，0 失败 |
| PrintTest 美术布局与全卡覆盖 | 5,551 项通过，0 失败 |
| OutcomeTest 战果、金币、重试与读档 | 79 项通过，0 失败 |
| HubTest 实际按钮、买包、上阵、装备、胜败整备与换关 | 51 项通过，0 失败 |

合计 5,940 项检查通过。已检查七个实际页面以及 1280 × 800、1280 × 720 下的胜敗营地截图；标题、四区入口和底部继续操作均无溢出。引擎导入、测试日志及截图错误日志未出现脚本或资源错误。

额外验证了：通关后购买升级再返回仍显示通关；失败升级后原关重试不重发旧收益；打开地图后选择另一可用区域能真正开战；战斗中回营再继续不重置血量。

运行工程后，在牌桌顶部进入“大本营”，或结束一趟战斗，即可使用新版。已有游戏窗口需要重新运行工程载入新的代码和素材。

本次实现为四区整备界面与胜败继续流程。基建沿用既有解锁节奏和建筑收益。此前完整剧情、自动训练、12 招与流派策划仍是后续目标，不计入此次实现。
