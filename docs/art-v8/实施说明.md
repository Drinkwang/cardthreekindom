# 拍案三国 v1.8：统一武将图集与产品美术

日期：2026-10-08。美术已接入实际游戏，完整产品玩法方案见 [产品策划案](../product-v3/拍案三国_完整产品策划案.md)。

## 本轮完成

针对旧版六名新版武将与其余旧卡面混用、脸部比例和留白不一致的问题，使用内置 ImageGen 统一重绘 **57名武将＋I01初始主角，共58幅头肩肖像**。全部保持旧纸、墨线与低饱和套色风格；儿童现实伙伴仍穿校服，保留年龄和身份。

五张原始图集均为4列×3行，实际1448×1086，每格362×362。前三行按固定卡ID排序，第五张最后两格为空纸底，不对应卡牌。取景读取原图实际宽高；主卡和小头像共用一个格位，小图统一轻裁切，不重新缩小旧全身立绘。旧美术保留作为资源缺失时的回退。

- 构筑：左侧选中大卡，右侧横向实际联动栏与将牌仓库；阵位、仓库、连招和上阵菜单共享统一头像。
- 基建：保留六槽建筑卡、仓库与同名合成。右侧组合链可以滚动，周期收益纸条和卸下入口常驻；金币变化保持选择、滚动与拖拽。
- 收益预览：直接使用真实结算规则；农田＋水井＋粮仓＋驿站显示 `6 + 6 + 18 = 30金币 / 30秒`、`60金币 / 分`。精制卡显示小数收益，不提前取整。
- 继续挑战：失败保留重新挑战/换地图，通关保留进入大地图；仍能返回大本营四区整备。

## 目标与当前实现

本轮实施美术和页面整理。游戏现有培养、随机武将合成和六将战斗联动仍沿用，**完整策划案中的取消武将练级、同名武将品相合成、全卡八流派及自动训练属于下一阶段目标**。策划案自包含剧情、拍击手感、挂机助力、经济、全武将与士兵/建筑速查、图集规范和制作验收，并明确这一区别。
