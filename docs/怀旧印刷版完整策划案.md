# 《拍案三国》怀旧印刷版完整策划案

版本：v1.2 · 执行稿 · 2026-10-03  
工程：`D:\Pro\cardthreekindom`  
方向：旧木桌、连环画、纸牌、朱印。用户已选定怀旧印刷，本轮直接按此方案完成整体迭代。

## 一、定位与体验目标

**把三国印成一叠值得收藏的纸牌：拍翻敌牌赚金币，回营把队伍养强，再把打下来的城池经营起来。**

这是鼠标操作的增量拍卡与多局成长游戏。核心动作是单击和划过；主要策略是耐力投资、上阵搭配、装备与带兵，以及出征路线选择。

三个体验目标：

1. 桌上看得清：姓名、兵种、人物与血量不被纹理和邻牌遮住。
2. 拍起来有力：轻拍、重拍、暴击和拍翻都有区分，连续划过不中断操作。
3. 收下来有用：武将、士兵、装备、建筑和城池都有图像，去向和收益可理解。

本版全面改造美术、信息呈现、反馈与说明；沿用当前卡池、地图关系、升级公式与经济参数，避免视觉重制同时改变已验证的成长基础。

## 二、完整核心循环

### 2.1 第一局与成长

启动 → 查看纸牌式主菜单 → 进入新野牌桌 → 拍击敌牌 → 耐力耗尽结算 → 大本营升级 → 继续出征 → 清桌 → 舆图选下一站。

第一局可以打不完，结算仍给金币。营地必须明确显示“下一次升级能提升什么”和“推荐下一桌”，失败呈现为积累，不能像死亡惩罚。

### 2.2 中后期

选择四条路线 → 收集与招降武将 → 上阵 → 为每将配装备与士卒 → 解锁更多携带位 → 克服区域 → 建筑放入城池 → 收取在线与离线收益 → 开包与强化 → 推进终局。

长期目标：完整收集卡牌、强化常用队伍、解锁全部荆州节点、建立稳定建筑产出。不同路线提供不同战斗和经济倾向。

### 2.3 持续进度

开启正式存档，菜单提供继续与新周目入口。返回菜单或退出保存现有成长，离线收益沿用当前上限与效率规则。新周目由玩家在界面确认后开启。

测试与截图使用独立测试档，不能把中期截图的伪造状态写入玩家正式存档。存档保持原数据格式兼容。只保存成长与城建，重新启动会重新铺桌，不保留局内血量。

## 三、拍卡规则

| 操作 | 伤害 | 耐力 | 反馈 |
| --- | --- | --- | --- |
| 单击一张敌牌 | 当前轻拍伤害 | 1 | 纸牌下压、局部拍印、一次伤害字 |
| 按住划过 | 轻拍伤害 ×2.5 | 每命中一张 2 | 短轨迹、逐张拍击、较大朱印 |
| 暴击 | 按现有暴击计算 | 按对应拍法 | 更强回弹、朱红标记与伤害字 |
| 血量归零 | 依现有收集/掉落规则 | 已包含于本次拍击 | 翻到统一卡背，向收集方向收束 |
| 耐力耗尽 | 本趟结束 | 0 | 战报与成长建议，回大本营 |
| 拍翻整桌 | 克服区域 | 依剩余耐力 | 克服状态与字印，打开下一站选择 |

同一次拖拽不会重复命中同一张牌；可以在桌面空白处起手。桌面永远只显示敌牌，不摆装备。底部常驻的是已上阵友军，不是可打出的攻击手牌。

关键数值统一从实际系统显示；界面重拍文案必须准确显示 ×2.5，不能四舍五入写成 ×3。

## 六、营地与经营

### 6.1 大本营

左栏是三层技能树，显示当前等级、下级收益、花费与可购买状态；中栏是本趟战报和推荐出征；右栏是武将养成。

右栏优先展示队伍肖像和战力。每将装备、兵位归在该将下方；装备有物品图，士卒有兵种图，转移装备继续标明原主人。滚动区域保持可操作，避免文字和按钮相互挤压。

### 6.2 城建

左侧城池列表显示城市缩略图、已用槽位与产出；中央显示所选城池的大图、建设槽位、建筑插画与强化按钮；右侧显示产出总览、合成与建筑仓库。

强化等级用标签显示，不能只靠更华丽的图片暗示。空槽显示清楚的放置入口；拆除前通过提示文案说明强化等级会丢失。功能建筑与产出建筑使用短标签区分。

## 八、美术规范

### 8.1 色板与材质

纸白 `#F1E6CA`；墨色 `#2B211A`；朱印 `#B8482B`；木色 `#674530`。四条路线用靛蓝、朱红、青绿、赭黄的小旗，特殊阵营保留独立辅色。

材质规则：插画可以网点和轻微错版，正文底保持平整；桌面中央低对比，磨损与道具集中外缘；全项目避免大面积脏黄与荧光色。

### 8.2 插画

连环画式有力墨线、有限矿物色、少量网点。人物胸像清楚，面部和武器轮廓有差异。关羽长须与偃月刀、张飞浓须与蛇矛、赵云银甲与直枪、甘宁头巾与铃饰是重点校验项。

士兵按兵种制作；装备按轮廓制作；城池区分河港、山地、平原和城门结构；建筑区分屋顶与功能设施。全部插画留安全边距，不能越过图集格位污染相邻卡牌。

### 8.3 卡框与排版

阵营、稀有度、类型互不替代：阵营以深墨字印表示，稀有度以星数+边角纹样表示，类型以图像与短标签表示。

卡面顺序：姓名 → 星级 → 插画 → 类型/阵营 → 血条与数值。详细技能进入悬停/详情，不挤进最小敌牌。保持约 1:1.38 的卡牌比例。

满桌使用不可见基础排列再加入小幅旋转，卡牌视觉上仍是散在桌上，但姓名与血条不被压住。卡池展开和商店展开时重新排牌。

### 8.4 控件

统一浅纸面板、深墨字、朱红主动作，按钮有正常/悬停/按下/禁用/焦点状态。字体优先清楚的中文屏幕字体，标题可使用宋体气质；小字不使用模糊的做旧纹理。

UI 图形由程序绘制，可伸缩；角色、装备、建筑和背景使用生成插画。避免把整张概念图直接裁成一套按钮和不可更新的假界面。

## 九、反馈与可用性

轻拍 100～160 ms、重拍单张 140～220 ms、拍翻 260～420 ms 为初调目标。一次伤害只出现一组数字；特效不捕获鼠标；高星光效不持续覆盖整桌。

舆图的已克服、可挑战与未解锁节点以符号和明暗区分，阵营颜色不承担所有状态信息。当前关卡显式选中。

窗口基准 1280×800，同时核对 1280×720 与 1920×1080；必要滚动只出现在养成和目录区域，拍卡区域不滚动。
