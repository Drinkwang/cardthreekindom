# 底栏压缩与居中 v23

2026-10-22。保持用户认可的紧凑外观，只将底栏内容下移居中；不移动战场敌牌，也不放开战斗配队。

## 当前规格

- 底栏112像素，小地图220×96；移除“地图”标题、印章和整条题签带，保留小地图本体。
- 底栏上下各留8像素，默认上阵卡牌垂直居中，小地图不压上边线。底部空白仍能滚屏，真实横滚条优先操作卡槽。
- 卡面88像素、头像44像素高，字号不变；装兵数量移到头像侧边，不用额外一行撑高底栏。六将加主角时，88像素卡面与8像素横滚条装入96像素容器。
- 比上一版140像素底栏多出28像素战场高度；主图地形、世界坐标、敌牌位置、收益规则及存档格式不变。
- 小地图密集分区省去文字题签；白圈与红心分层绘制，避免后画的白圈遮住已有红心。仍对应真实存活牌，不添加假点。
- 战斗中队伍只读：不能上阵、下阵、重排、自动配队、换卸装备、派兵或撤兵；返回休息后才能修改。已有生产保护保留，本次补有效持卡的回归对照。
