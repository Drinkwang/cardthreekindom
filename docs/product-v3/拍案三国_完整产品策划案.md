# 《拍案三国：操场就是荆州》完整产品策划案

**版本：产品目标 v3.0｜2026-10-08**  
**用途：决定做什么、先做什么、怎样验证；供策划、程序、美术、声音共同执行。**  
**事实基线：玩法沿用 Godot v1.7；本轮美术 v1.8 已重绘现有57武将＋I01共58张统一肖像，收入5张图集并接入游戏，两种窗口高度的实机检查已通过。除标注“已实现”的内容，均为目标设计；所有新系数、时长和指标是起测目标。**

小时候，你和短发的青梅竹马一起趴在木凳上拍卡。今天，这个小霸王连你没上桌的牌也抢走了。你握着最后一枚五角，向学校门口的何婆婆买下一包三国卡。包装纸展开，操场在想象里变成荆州。你从新野的几张薄牌开始，一掌一掌练出自己的打法，直到整个操场都有人愿意坐到你这一桌。

产品的重心是**玩家亲手拍卡，武将与士兵改变这一拍，修炼和建筑帮助长期成长**。前期靠一次次实际失败学会翻牌，中期靠组合而非只加数字突破，后期用训练与经营积累，再回来亲手冲关。手动的动作感、看懂组合后的成就感、童年关系的变化必须同时成立。

## 1. 产品边界与本版决定

### 1.1 面向谁，承诺什么

首发暂按离线 PC 单机买断产品规划。目标玩家喜欢卡牌组合、放置积累和短时回来调整，也能接受前期亲手拍几桌。一次主动游玩建议为 10—25 分钟；允许随时离开，回归时在两分钟内知道赚了什么、哪里能变强。鼠标是主操作，键盘与辅助模式补足可访问性。

主线起测范围为 **12—18 小时实际主动操作，穿插 5—10 天自然训练积累**；较重手动玩家可更快，低频玩家更慢。这不是强制日历、上线承诺或已验证时长。把主线拉长的依据应是新组合、新敌阵和关系事件，而不是把同一关血量放大一百倍。

| 产品支柱 | 玩家应感到 | 必须拿得出手的证据 |
|---|---|---|
| 一掌改变一桌 | 拍下去有纸边、掌风、桌响；后期这一下带起连拍与属性 | 同一旧桌在成长前后的操作与结果明显不同 |
| 小牌也能接大招 | 看懂低星接口，主动保留它组成队伍 | 换掉接口卡后，预览显示哪条组合关闭 |
| 经营帮助冲关 | 训练、城市和修炼为下一次挑战提供具体改变 | 收入分账；预计几分钟能买哪项助力 |
| 操场上的人一直在 | 追卡的动机改变，阿棠承担错误，伙伴参与试招 | 中段还盒、后段公平决赛、结局现实回收 |

首发不以联网、竞技排名、真实货币抽卡、强制每日任务或赛季重置为支撑。付费暂按一次购买游戏；所有卡包和合成只使用游戏内资源。后续可讨论独立美术皮肤或续篇，但不能把缺失主线和关键功能留给付费补齐。

### 1.2 统一此前几版冲突

| 问题 | 本版唯一规则 | 对现有版本的处理 |
|---|---|---|
| 武将能不能升级 | 不设独立经验等级，不用金币培养武将；固定星级，重复卡提升品相 | 当前培养按钮与 `hero_lv` 仍存在，列入规则迁移任务 |
| 星级与品相 | ★表示固定强度与职责；原版/精制/珍藏表示同名收藏成长 | 合成不改姓名、★或技能次数，不随机升星 |
| 自动是不是手动的 1/100 | 不采用固定 1/100；先测 25%单拍、每秒1次，再逐步至40% | 自动战斗尚未实现；不能把建筑收入称作自动拍 |
| 升级图是否承载流派 | 网图只管拍力、耐力、容量与自动/离线助力 | 八流派在卡组中形成，不另做八条复杂天赋树 |
| 基建是盖房升级吗 | 六槽装配建筑卡，来源、加成、追加、倍率组成收益 | 30建筑已接入；不恢复建筑 Lv、拆除损耗 |
| 战后是不是只能点下一关 | 通关、失败都能继续商店/构筑/升级/基建 | 失败重试/换地图，成功主动进入大地图 |
| 阿棠抢卡是不是为玩家好 | 抢没上桌的卡确实越界；她中段主动归还并认错 | 不把终章胜利当取回个人物品的条件 |
| 美术要不要各种风格混用 | 主版统一旧连环画套色印刷；同类卡统一图集和构图 | 像素等探索作为独立方向，不能混入主卡池 |

## 2. 当前产品盘点与目标差距

以本轮读取的实际数据为准，当前共有 **169 张卡：57 武将、24 士兵、36 装备、30 建筑、21 城池、1 主角**。21城、9类卡包和四条地图路线可复用。主角和现实伙伴的叙事角色不等同于普通抽取单位。

| 模块 | 已实现基线 | 完整产品还需完成 |
|---|---|---|
| 拍卡 | 单击轻拍、拖过目标重拍；有限耐力、翻牌、结算 | 输入预算边界、真实扣血工资、可控反馈、同桌接管与持久化 |
| 大本营 | 商店/构筑/升级/基建四区，持久战果与重试入口 | 失败原因、下次改变预览、训练状态条、故事入口 |
| 武将/兵/装备 | 个体装备、挂兵、金币培养；六名核心将实际联动 | 取消武将练级；全卡结构化效果、品相合成、预设与保护 |
| 基建 | 30建筑、每城至少六槽、组合结算、品相合成、在线离线、旧档返还 | 城市概况、模板复制、平衡与功能建筑说明 |
| 修炼 | 八项浅前置技能和纸面界面 | 少量网状节点、自动拍/继续/下一关、离线训练 |
| 放置 | 建筑在线/离线收入 | 可重刷训练桌、真实自动行动、快照与同规则离线 |
| 故事 | 三国题材与现实角色部分素材 | 八章事件、序章操作、还盒与决赛、日记与奖励标记 |
| 美术 | 怀旧印刷体系；v1.7全建筑，v1.8全部57武将＋I01统一5图集已实机验收 | 士兵与装备规范、完整情绪演出 |
| 长线 | 现有指数式21城血量 | 章节目标、63档训练、8精英桌、收集终点与经济仿真 |

现有六将联动是朱灵/文聘雷印、韩玄/程普烈火、周仓/马良追击；它们是可玩基础，**不是本案八流派已完成的证据**。全卡目标册覆盖57将、24兵、主角及拟新增关银屏共83条设计记录；关银屏目前不在169张现有卡中。新增后目标卡池为170张，数据和美术均需明确版本。

当前部分卡包文字保底高于池内最大星级，例如长沙、桂阳、零陵。上游配置必须修正并自动校验，不能只改展示文案。本版不直接手改生成的 `data/*.json`；实施时修改单一数据源，生成后核对数量、效果与资源映射。

## 3. 核心循环与首30分钟

### 3.1 三层循环

**一拍内：**选择目标 → 支付耐力 → 首拍与追加 → 属性/状态/有限范围 → 翻牌与即时反馈。

**一桌内：**看敌阵 → 找薄牌或拆护阵 → 用有限耐力产生有效收益 → 清桌成功或耗尽失败 → 带着钱与卡回整备。重试会重新铺满血敌牌；玩家资产不重置。

**长线：**整备接组合 → 手动突破 → 城市与新训练解锁 → 挂机和建筑供给 → 修炼与同名合成 → 新组合/新敌阵 → 下一段故事。没有强制清空收藏的“重生”；首发终局采用挑战档与收藏目标。是否加入下一轮暑假，等主线验证后单独决定。

### 3.2 可制作的新手流程

| 经过时间目标 | 场景与操作 | 玩家获得的认识 | 验收点 |
|---|---|---|---|
| 0—2分钟 | 木凳旁轻拍、一次短滑拍；阿棠抢走原盒 | 这是一起长大的熟人，但她越界了 | 两个操作足够，不连续强制失败十次 |
| 2—4分钟 | 五角买正常5张基础包；包装纸转新野 | 重新开始，薄牌也能翻 | 包含至少3个不同可用ID，不给名将跳关 |
| 4—8分钟 | 新野6目标，先翻1—2张；耗尽回营 | 失败收获可留下，钱来自实际拍动的牌 | 默认初包不能清桌；战报写出具体所得 |
| 8—12分钟 | 二选一先点拍力/耐力，立即重试 | 下一掌确实不同 | 1—3次有效失败买得起一次助力 |
| 12—18分钟 | 给一张确定接口卡；试出来源→条件连接 | 加一张卡能改变动作，不只加战力 | 对比预览和实战一致；引导可跳过 |
| 18—24分钟 | 新野首通后反复练习，解锁自动拍 | 我能离开去整理，队伍仍练 | 自动单拍25%，每秒1次；开关可见 |
| 24—30分钟 | 选樊城/中庐；体验一桌厚牌失败、短离线报告 | 冲关和训练分别有用 | 能回到指定训练；不会自动跨过剧情 |

时间目标以普通新玩家为参考，序章约2—3分钟可跳过。首包不随机锁死新手：默认可复现种子或受约束抽取，保证三兵接口齐全；普通后续包仍用公开池。赠送只承诺普通接口，不用★6来掩盖开局失衡。

第一桌目标：开桌耐力6，轻拍消耗1、重拍2且基准×2.5；最低两张薄牌能在预算内翻倒，厚牌留到下轮。薄牌HP应由初包实际基础拍力倒推，建议起测薄牌为约2—3倍轻拍B，而不是直接把旧60总血与新战力混用。正常失败三轮后至少一种便宜改动可促成首通；若必须纯点击二十轮，先调收益和HP。

## 4. 剧情：八章与人物弧光

### 4.1 两层世界与关键物件

现实是一所暑假向街坊开放的学校操场，角色约11岁；三国是孩子赋予纸牌和小地盘的想象。现实木板的裂纹与地图河流共用轮廓，粉笔圈与城墙重合，木桌响声始终留在夸张技能里。离线的几小时解释为伙伴轮流练和城市运作，不写成孩子通宵拍牌。

现实五角只购买第一包；游戏金币是幻想资源，不能兑换现金。原卡盒、婆婆卖的新包、后来收集的卡分别记录。阿棠归还的盒内保留折角和玩家画过的记号，不能用抽到同名卡替代原物。第一包可锁为收藏，粉笔圈与自画招式本持续回收。

### 4.2 角色可演出的变化

小野从不敢说“不”到敢提出公平规则，从只想追卡到愿意邀请新人。他喜欢记卡背，手劲不大但会研究。台词从“这张还没上桌”到“卡已经还了，现在这局是我自己想打”。

唐棠/阿棠是短发、宽松短裤、卷袖、晒黑膝盖的小霸王女孩。她反应快、懂滑拍，抢盒子是自以为熟悉就能替人决定。她不靠隐藏善意洗掉行为；先制止别人的越界，被指出自己也做过，再主动把盒子按原顺序还回，具体说“没上桌的我也拿了，是我不对”。成长后仍响亮、好胜、有劲，只会先问“这局拿哪几张出来？”

何婆婆经营学校门口杂货铺，给正常包，提醒“薄牌先找边”“赢上桌的，没上桌的别碰”。她不送神卡、不替玩家讨回全部关系问题。雷飞G00是另一个伙伴，记录“先起名字再把龙拍出来”，中期认真对打并成为轮流练习的搭子。铁头、阿舟、算盘分别教厚牌攻坚、分桌连锁、长线供给；都有初见、失败、获胜、回访台词，不全是阿棠的跟班。

章节按事件门槛推进，不按现实日期卡住。分支城市可换顺序；剧情队列保证“制止越界→归还→约赛”的先后。离线和自动可以积累资格，关键情节到玩家回归后播放。终章资格推荐为襄阳印、临湘印、泉陵印及夷陵/公安通关，明确写在地图；全部21城征服另记成就，不能把冠军结局和全收集混成一个条件。

终局关羽有70%/30%血线表现变化。护阵来源存在时减伤依次30%/20%/10%，翻倒护阵则0；不锁血、不强制回血、不临时无偿补兵。爆发越过阶段直接播当前状态，不能为了看三段演出扣回玩家伤害。阿棠的现实卡盒摆在场边，冠军局只记分；幻想奖励照常入账，不表示抢走她现实收藏。

| 21江陵 | 公平决赛 | 15目标、关羽主牌、可拆护阵、无锁血三段表现 |

每城另设训练Ⅰ/Ⅱ/Ⅲ共63档，开放基于该城首通与实战能力，不增加63个新剧情地点。训练档只在HP、普通牌结构、掉落倾向和每分钟收益上变化。8个精英桌分别检验连拍、刀锋、重拍、烈火、雷甲、风印、属性转换与军团供给；首发精英不要求凑唯一指定六星队才能打。

数值重标定使用“本阶段标准可获得队伍”而非最强满收藏。D定义为该标准队伍在一桌耐力预算内预计造成的有效总伤害，单位与敌牌HP一致；常规新关目标HP先落在0.85—1.10D，薄牌分布提供失败进度，阶段首领可到1.15—1.30D并提供拆阵收益。若下一次增长只能靠数小时等钱，先给替代桌、确定接口或成本调整。

章节可试玩目标：前半段20—40分钟至少一次新行为，后半段每次回归都有一项可做决定。终章前最多存在2—3个长期材料目标，不能同时要求全将珍藏、全城完美布局和全部修炼满级。

## 6. 拍卡手感、输入与失败体验

轻拍是一次命中存活牌并成功支付1耐力的行动；重拍划过一张新目标是一个行动，默认2耐力、基准×2.5，同一手势不重复命中同一牌。先应用减耗再支付，最低1；剩1耐力无减耗只能轻拍，不能扣为负数。

重拍沿路径显示短掌风与已扫目标细线。空白处允许起手；路径宽容度随辅助设置变化但不暗增伤害。目标轻微位移时交互区同步，不把残血牌震到桌外。摸牌详情采用独立查看输入或短停留，不与拍击误触。每次有效手动输入至少提供声音或视觉之一，低动态模式也有掌印、轮廓与翻面。

战后不弹满屏统计打断下一次改动。底部先写城市、通关/未通关、本局金币、翻牌数；展开才看来源和触发。失败理由以实际差额选择：还差多少生命、少几次耐力、某个来源缺失、护阵未拆。只推荐一项可执行改动，同时保留全部四区。

失败默认按钮“重新挑战”，次按钮“换地图”；成功默认“进入大地图”。升级、合成、配队之后仍保留上局战果且不再发奖。自动继续只是倒计时开始下一桌，可随时暂停；默认不自动购包、不自动合成、不自动花钱。

重试保持队伍、训练选择和玩家资产，敌桌重新生成；首通奖励唯一。主动退出按已产生有效收入结算，不发额外底薪或虚构动作奖励，以免刷空进空出。失败可能得到卡和钱，也要显著告诉玩家离突破近了哪里。

## 7. 武将、士兵、装备与合成

### 7.1 容量少，连接明确

主角常驻不占位；携带位初始3，最终6。每位可放一名武将或一支独立士兵。解锁带兵后每将先1兵位、后2兵位，全队最多6支挂兵。目标方案的限制小于旧版每将3兵位，迁移时多出的编队返仓、资产不消失。

同名武将只上阵一名；同名士兵全队仅一支有效编队，独立/挂兵合并检查。士兵默认技能作用全队拍击，除非卡面明确指定主将；挂兵全额加入基础战力，不占携带位。这样一张有用的低星兵能提供接口，又不会退化为六份最高星兵堆同技能。

装备仍由每将自己的兵器、铠甲、坐骑、兵书、宝物槽管理；士兵和主角没有装备槽。一件实体卡只能挂一人，转移需展示来源。五槽逐步解锁，前期只学兵器、铠甲。36种现有装备先覆盖来源与分类数值，不同时再引入一套随机词缀与新宝石资源。拍力、普通增幅、火/雷/风/刀增幅、耐力、经济词条必须标清所属层。

开桌锁定快照；中途整备改动下一桌生效，手动接管同桌不重置计数、掉落或技能冷却。提供“冲关”“训练”两套预设起步，后扩至4套；保存卡ID、品相、装备和挂兵引用。缺卡预设显示差额，不偷偷换成别的卡。

### 7.2 固定星级与可理解的品相

| 档位 | 原版武将基础战力起测 | 士兵基础战力起测 | 职责预算 |
|---|---:|---:|---|
| ★1 | 无现有武将 | 0.2 | 狭窄但独特接口、少量属性转换、开桌助力 |
| ★2 | 1 | 0.6 | 先手条件、少量来源、补刀、轻拍辅助 |
| ★3 | 2.5 | 1.2 | 稳定来源、状态桥、有限回收、条件增幅 |
| ★4 | 5 | 2.4 | 流派主体、有限范围、军团规则 |
| ★5 | 9 | 无现有士兵 | 大来源、重拍爆发、条件斩杀或供给 |
| ★6 | 15 | 无现有士兵 | 完整追加、强倍率、转换、穿透、周期规则 |

现有武将★2/3/4/5/6分别6/19/14/11/7名；士兵★1/2/3/4分别5/6/9/4种。高星具有更大基础战力和更广作用，低星保留窄接口。没有为填齐六档虚造高星士兵，也没有要求每个武将分别设计六份技能。固定星级下通过同名收藏成长。

武将和士兵：3张同名同品相→下一品相，原版×1、精制×1.35、珍藏×1.8，**只强化自身基础战力**，技能次数/来源系数/触发周期均不变。原版关羽15→精制20.25→珍藏27，三种都追加1道完整拍击；张飞×2不会因珍藏变成×3.6。装备后续若接品相，先只强化数值词条，禁止扩大触发次数和额外派生链。

建筑已实现的品相会强化产出与数值助力，周期、次数不变；与武将规则区别写在类型说明中。不要用含糊的“全效果增强”统一二者。

### 7.3 安全合成流程

仓库页显示“还差N张”，点同名卡看合成预览：总计3张同名同品相，主体1张＋材料2张，合为1张下一品相。默认排除上阵、挂兵、已装配建筑、收藏锁定、带装备绑定及故事唯一卡；材料不足可跳商店定向补牌。确定合成不扣额外金币、不随机失败、不改星级，结果回仓库，不自动换阵。

如玩家主动想融合已绑定卡，先选保留主体，再显式转移装备/挂兵，并确认释放材料。原有装备不能静默消失。一键合成只处理未锁、未绑定的仓库重复卡，结果列表可撤回到合成前快照一次，撤回期间所得结果不得已被继续消耗；若此撤回成本过高，首发至少提供预览和逐批确认。

普通敌将捕获可保留为“获得待招募卡资格”，成本和保底提供确定进度。G00雷飞、G56青梅竹马从普通敌池及招降池移出，按主线邀请得到；不把现实儿童写成金币俘虏。I01主角不可合成、出售、卸下。

### 8.2 行动与拍击段

一行动只支付一次耐力、掷一次暴击、规划一次追加。关羽追加权重1，张辽追加两段各0.5，于禁每第3行动追加0.4；来源可相加但追加不会再规划追加。雷飞无追加时补0.35，有追加时只增强第一段0.25。每个完整段重新生成普通和可发动属性，按该段目标判断条件。

追加按关羽→张辽两段→于禁→雷飞新增的固定顺序执行；雷飞增强总是作用于现有第一道追加。关羽及常规集中追加优先原目标，原牌已翻倒则选桌面距离最近的存活牌，同距离按桌面编号。张辽优先首拍之外两张不同存活普通牌，无合适普通牌则回存活原目标；仅剩首领时打首领，原目标已翻且没有合适普通牌时选最低剩余生命的存活目标，同生命按编号。已计划的段找不到存活目标则停止，不凭空补出新牌。

设轻拍基础 `B = (1 + 有效出战基础战力 + 装备固定拍力) × 修炼拍力倍率 × 明示全局拍力倍率`。每个来源只在其声明层加入一次。行动基准 `A = B × 输入强度 × 暴击/招式倍率 × 自动系数`；手动系数1。段基准 `P = A × 段权重`。

定义普通剩余系数R、普通增幅U、该属性来源系数C、即时特殊增幅T、该属性增幅E、易伤v与破甲a：

`普通 = P × R × (1+U) × (1+0.1v+0.1a)`  
`某属性 = P × C × (1+T) × (1+E) × (1+0.1v)`

同层加法、不同层乘法。原始1P转火0.1P和转风0.08P时，R=0.82；不从剩余普通再二次抽8%。吕蒙只向已有属性E加入100%加本段普通U，不回读自身结果，不复制暴击、输入、易伤或破甲。伤害工资按真实扣血，演出预览可显示理论伤害，但二者分账。

**用户示例闭合：**固定轻拍B=100，无装备、暴击和状态。关羽＋拟新增关银屏＋张飞，首拍权重1和追加权重1；每段普通100＋火60×2=220，行动共440；只扣1耐力。重拍基准先变250，行动共1100，默认扣2耐力。自动25%则同一轻拍行动110，自动系数只乘一次。换队会改变实际B，预览不能假定高星换低星后B仍为100。

**低星保留例：**糜芳★2在首拍前给无易伤牌1层，打开沙摩柯强刀源和魏延普通条件；高星纯战力替换未必更好。黄巾残部★1把0.08P转风，本身几乎不增裸总伤，却让张允挂易伤、黄祖复制和吕蒙增幅有了对象。预览同时比较基础拍力差与关闭的规则，才能让低星价值可信。

### 8.3 时序、状态和防递归

执行顺序固定：支付与计数→到期检查和明确先手状态→主目标属性条件快照→规划所有段→逐段普通/火/雷/风/刀→该包实际命中后状态→有限范围副包→行动末回收与收益→成功/余火/失败。命中后新增状态不反向增强已经结算的伤害；可增强后续包或追加。

破甲仅普通+10%/层，易伤所有伤害+10%/层，均最多3层、共享6秒；换桌清空。火焰是即时属性，燃烧是明确点燃入口产生的持续伤害，有火不自动点燃。燃烧最多3层，每层3秒、每秒跳一次，保存施加时P；不吃张飞即时特殊倍率，也不再次触发拍击与扩散。耐力耗尽后最多等待已有余火3秒，可由余火清桌但不能借此新点火或回收再开行动。

范围复制取主源最终理论伤害、扣血截断前值；副目标不再重算源倍率和受伤层，不附带命中状态，不再复制。该段已生成的属性复制预算不会因普通包先翻倒主目标而取消，仍向有效存活副目标结算；命中后状态则必须有实际有效命中，不能向死牌施加。每段每属性最多2个不同副目标，合并同目标系数后择大保留，平局按桌面编号。完整追加、普通衍生包、属性复制、燃烧四种事件有不同类型，禁止靠“发生伤害”统一触发全部能力。

甘宁的最多两张普通副包按自身规则接受普通增幅，不生成属性、不推进拍击计数、不触发关羽。全部耐力回收共享 `floor(开桌耐力×30%)` 上限；0耐力不允许新行动。战报能展开每段来源、目标、实际扣血和触发原因，规则清楚后再加华丽表演。

## 9. 修炼网图：少量助力节点

网图呈“根节点＋三条短支路＋少量横连”，首屏显示10个主要节点；长期数字放入拍力与耐力详情，不无限铺小点。节点三状态同时使用形状/文字：已学✓、可点↑、未解锁锁。选节点右侧展示现在→下一档、花费、作用和条件，底部重试入口不消失。

自动强度在自动拍详情中25→30→35→40%四档；不另铺四个视觉节点。暴击、财路等旧项作为拍力或助力详情的可选小项，先收敛首屏；核心平衡成立前不增加十种资源或复杂洗点。首发修炼支持一次免费调整有限功能分支，长期拍力/耐力投资不惩罚重配队。

起测费用以本阶段基准可训练每分钟金币Y归一化：早期关键解锁约3—5分钟Y，中期5—15分钟Y，末期15—30分钟Y。拍力前段费从12金币、每档×1.16作为仿真起点，耐力从10、每档×1.18；跨章节价格需由收益表重新标定，不能任由收入暴涨而成长费停在个位数。拍力后30档是否降为×1.06必须和后期HP一起测，首发不把无上限复利作为自动兜底。

## 10. 自动、离线与手动的分工

手动负责速度、选择、重拍专属词条与关键爆发，自动负责稳定训练。基准测法：同队同桌、无重拍条件，手动2次轻拍/秒，对比自动1次/秒×25%，自动DPS约手动12.5%；升级40%约20%。固定1/100在该速度假设下只有0.5%，容易让组合看起来没工作；因此先不采用。以上比例不等于金币效率，金币取决于桌次、耐力、目标和失败，必须整桌实测。

自动策略首发只有“薄牌优先”“主牌优先”“按指定顺序”三种，不做几十个条件脚本。单拍执行完整卡组规则，自动系数只乘A一次。默认训练已通城，未通关地点需要“自动下一关”授权开关；失败回指定训练，不无限撞同一堵墙。跨剧情资格到达后暂停新剧情推关、训练继续。

自动与手动同桌互斥调度：有效手动命中优先，自动延后一个节拍，不同时打同一目标、不借接管重掷暴击。进入构筑/商店可继续独立训练快照，头部明确“正在训练：夏口Ⅱ”；改阵默认下一桌应用。开关不会重置已支付耐力或Buff，暂停冻结战斗时钟，建筑仍按其时钟生产。

自动继续训练为可见开关，自动下一关为另一开关。失败后训练倒计时3秒可取消；手动冲关失败默认停在四区，不悄悄带走玩家的查看机会。自动不花钱、不招募、不拆锁卡、不代替关系选项。

离线分为建筑账与训练账：建筑沿用已实现周期，但当前建筑离线基础效率为50%，通过挂机效率修炼及装备/武将离线收益词条提升，最终封顶100%；不能把在线平均收益默认当作离线所得。训练保存战斗快照、策略、种子、计数、时间和上次结算ID，恢复时按实际轮次批量运行。已有燃烧、余火、耐力回收、鲁肃周期供给不能用单次峰值乘小时替代。目标是未触上限时，同队同种子在线与离线的规则计算原始收益一致；实际入账再单独应用明示效率一次，不能在每个伤害层反复扣。

离线训练建议起步2小时，最终8小时；建筑当前基础8小时并可由功能与修炼增至封顶24小时，两套上限分别显示。回归页先列金币、重复卡、有效时间、上限损失以及待看剧情，一次入账即保存，重开不会第二次领取。离线过长只舍弃超过容量的时段，不销毁现有资产。

## 11. 基建：建筑卡是另一套简单构筑

### 11.1 已实现规则保持稳定

三处非起点区域通关解锁，每可经营城市至少六槽，同城同名一张。30建筑包括10来源、12组合助力、8全局功能。拖到空槽装配，城内换位只是整理不产生邻接加成；点击选中后可卸下、原品相返仓。

每10秒一次基础周期，追加不推动计数。按来源→固定加成→同层百分比→周期追加→追加倍率→明示全局加成结算，不递归。调换/装卸重开该城市周期，仓库合成不重开城市；这是防止快到时搬牌刷钱的规则，操作页需短提示。

同名合成3原版→1精制×1.35、3精制→1珍藏×1.8，不扣金币、不改★，装配卡保护。数值系数增强来源、加成与追加系数，次数/周期不变。全局唯一功能跨城同名取最强品相，不叠同名副本；烽火台例外可叠时长但仍受24小时封顶。

### 11.2 一个可核对的收益例

原版农田每10秒4金币，水井每张农产每次+2，粮仓每3次追加1次，驿站追加+100%。三周期分别 **6、6、18**，30秒30，在线长期平均60金币/分；当前默认50%离线效率下，完整周期的离线平均入账为30金币/分，提升至100%才与在线60相同。再放木栅追加+25%，同层追加倍率2.25：第三周期6+13.5=19.5，30秒31.5，在线平均63/分、默认离线31.5/分；不能把木栅再乘1.25算成2.5。

若同时有菜地和农田，水井分别给两张来源+2；粮仓复制实际农产基础总额。珍藏粮仓仍每3周期追加，复制数值系数1.8，不变每1.67次。具体全量效果以附录的30建筑实施表为准。

### 11.3 经营体验改进

一城首屏保持六卡＋一条最有意义的收益链＋仓库，组合栏默认说明“每30秒发生什么”而不是只报小时大数。多来源可折叠，休眠卡写缺少的类型/来源，不用空箭头误导。平均产出、实际账单、全局功能分别呈现，人物战斗技能不被建筑金币触发。

中期提供城市概况表、按名称搜索、农产/工坊/商贸/水运/民生筛选；后期可保存4套建筑模板。复制模板只装现有空闲卡并预览材料差额，不跨城自动抢卡，不吞已有建筑。城市风景的变化仅表现已装组合，不额外加入必须点满的建筑地皮升级。

来源星级梯度1/3/4/8/16/32/64只是当前规则，不等同于已平衡经济。以城市解锁、重复卡取得、功能唯一和战斗收入一起仿真；高星来源强，低星井/木栅仍能接收益。避免20城放同一最优模板成为机械工作，最多先做3种明确城市专长，必要时支持批量应用。

## 12. 经济、掉落与商店闭环

### 12.1 钱只按明确来源增加

主币只用金币，重复卡本身就是合成材料。故事印为资格标记、不是每日消耗货币；先不增加宝石、体力药、粉尘、木材、粮食五套日常资源。三类收入独立：实际伤害工资、固定翻牌金币/卡、建筑与训练账。

一桌金币起测公式：`工资 = 实际累计扣血 × 地区工资系数`；`翻牌 = 各牌固定基础金币 × (1+本牌适用翻牌加成之和)`；首通奖励固定且唯一。区域系数随阶段调，不用剩余HP、理论溢出、燃烧层数或特效帧数重复发钱。训练失败保留真实工资与已翻牌所得，没清桌不能推进清桌奖励计数。

可核对例：B=10、轻拍1次/耐力、耐力6，6张生命10目标，工资系数0.1、每牌翻牌2、无加成，清桌收入6工资+12翻牌=18；首通另发唯一10则首次28。提高拍力但仍一拍一牌不会凭过量伤害增加收入。某将翻牌+50%只把12变18，工资仍6；若普通训练每桌18、桌战6秒+整备3秒，则每分钟约120金币，不得用“每分钟6桌”的旧假设算108。

金币主要消耗在修炼、固定卡购买、卡包、普通将招募；武将培养取消后重新预算。建筑合成免费、卡品相免费，不再把同一进度扣两次钱。期望训练收入和城市收入应让几次失败可买一次小助力，中后期10—20分钟训练能接近一个目标，不以此保证每次出六星。

### 12.2 抽包与确定补牌并行

保留何婆婆九类包，开包是惊喜，定向单卡是组合完成路径。商店每次展示包中全部候选ID、数量、星级上下限、当前保底进度和实际价格；不把“已购买2次”的涨价藏起来。当前每买涨价×2.4需重评，目标先以章节固定价起测，避免玩家开十包后永久买不起。

基础包出低星接口与初装备；地区包偏地区，但关键组合来源至少一个可确定获得。首通给明确选择三选一接口或固定卡资格，每章至少一种稳定补牌路径。定向重复卡建议约同阶段3—5分钟金币/张，★5—6通过较长成就/精英或捕获进度，不把长期目标全部放进纯随机池。

掉落分首通、训练、精英：首通给系统与组合入口；训练给普通重复卡和工资；精英给规定主题选择与稀有资格。敌牌翻面只发一次，装备只来自包/确定商店，不混进桌面敌池。已拥有的故事唯一卡不会成为垃圾重复；重复掉落转为明确可选普通素材，转换表须公开。

卡包概率预算必须来自实际候选权重，保底≤池最大星级且候选非空。9张原版才能得到1张珍藏，因此既要防材料稀缺，也要防某低星一天刷数千份塞满仓库。仓库以数量堆叠、合成进度和收藏锁处理，训练达到存储上限时停止收卡或转换为可追踪金币，不静默丢牌。

### 12.3 失败正反馈与防刷边界

失败后金币不是安慰奖，应来自玩家真正伤害和翻牌；变强路径包括拍力/耐力、补来源、换重拍条件、拆护阵、换地点训练。首次连续三败可出现婆婆/伙伴一句提示和普通接口选择，奖励按事件唯一，不随重试无限发。

首通、故事、开桌供给、离线、合成都有事务ID。空点击、击打翻面牌、溢出伤害和重复开战报不发奖励；范围复制不按复制事件次数另发奖励，但它造成的实际扣血仍计伤害工资，首次翻倒敌牌仍领取该牌金币和卡收获。消耗、结果、绑定迁移和存档提交作为同一事务；失败回滚，不在文件写半截时让玩家丢三张素材。

### 13.2 怀旧印刷不是把文字做脏

主风格：旧连环画线描、低饱和套色、温暖纸底、少量错版和磨损、木桌环境。米白约`#E6D6B8`、深墨`#302821`、朱砂`#9D3D2E`、靛青`#3E5960`、赭黄`#B28C4A`、墨绿`#3E6050`是起点，以实机可读性调整。主墨负责阅读、朱砂只负责重要动作/选中，金色主要给星级与收藏品相。

大标题可书法，姓名/效果/数字使用稳定字体；中文和动态数值由代码排版，不烘焙进AI卡面。正文区域压低纹理，对比和字号优先，最小有效正文建议16px/1280宽，主要卡名22—28px。720高采用缩短留白与可滚区，不能缩到10px把信息硬塞全屏。

头像、星级、阵营、品相、技能职责固定位置；阵营用印章加文字，状态用图形加字，不能只靠色盲难分的红绿。画面复杂度来自精美场景，不来自四层边框和满屏角签。大本营四插画保持主入口，构筑、基建用同一纸面顶栏与战果底栏。

### 13.3 武将统一图集的生产规范

v1.7的突出问题是部分武将换了精美新图，其他仍沿用不同构图，缩略图脸大小、视角与色阶忽大忽小。本轮v1.8已将全部57武将＋I01重绘为58张统一肖像并收入5图集，接下来按下述缩略图标准完成实机验收。**仅把不同旧图拼到一个PNG不会修复视觉不一致。**后续同样先按同一参考成批生成/修订，再按稳定ID收入图集。

现有57武将分批图集＋1主角；关银屏新增后追加明确格位，士兵24种另成同风格图集。每格采用相同半身高度、头顶留白、面部占比和胸肩位置，背景同一浅纸/旗影深度；魏靛青、蜀朱红、吴墨绿、群雄赭黄，现实儿童保留生活服装和年龄。不同人物靠发型、胡须、头盔、武器与神情辨识，不靠换一套绘画技法。

建议后续制作基准格512×512，采用统一方形头肩源图；竖形主卡通过纸框容纳同一原图，不强拉伸。当前v1.8实际362×362原格用于40/64/128px头像已完成验收。脸部安全区位于上半部中央，周边8—12px隔离与边缘延展；最终图集尺寸依据实际格数与引擎预算决定。清单记录ID、文件、行列、格位、头像裁剪区、版本、提示词与审核状态；渲染使用同一头像裁剪映射，不能每页各自凭感觉截脸。

验收四尺寸：完整卡面、128×128头像、64×64仓库图标、40×40战斗/链路图标。40px优先脸/盔强轮廓，去掉细小背景与完整武器；同一源图可以有标准化近裁，不需要为了小图重新变成另一画风。图集不含名字和星级；姓名、职责、星级由UI绘制。轻微1%裁边不得削掉额头、下巴或关键武器。

制作顺序：先六将样板的统一标尺→全现有将批次→现实人物→兵→装备，再核对全图鉴和所有上阵缩略图。主角/阿棠/雷飞要和剧情立绘认脸一致；不把现实伙伴生成成成年将军。每批至少一次整页缩略图联看，检查重复脸、串格、空格、物件越界、甲胄年代语汇与亮度跳变。

### 13.4 构筑与基建的本轮精修方向

构筑上方5—6个上阵小卡用统一头像与固定文字栏；选中区大幅人物卡强调“技能＋品相”，移除目标版不该出现的Lv与培养按钮。右侧组合横幅使用实际上阵头像、来源→增幅→追加/范围图标，展示本队真实生效链，不永远画关羽、张飞却上阵别的人。仓库缩略图高度一致，名字和星级不挤图。

基建保留用户批准的六槽大场景卡与右侧组合流程，卡图约占卡高55—65%。来源/助力/追加/倍率只用一个职责小标，品相采用角签；选中朱红细描边且文字仍清晰。右侧收益链优先显示农田4→水井6→粮仓第3次→驿站12；底部仓库横向卡列，建筑卡/同名合成页签，不恢复“升级建筑”等冲突入口。

新美术实装要以真实1280×800、1280×720截图验收，不能以生成参考图中文字可读作为产品通过。金币tick不重建节点、不跳滚动，不销毁拖拽引用；选卡、搜索、拖动、合成之后位置稳定。异步换图应先保留占位大小，再渐显，避免加载导致卡列跳动。

## 14. 爽感、声音与演出预算

成长反馈分四档：初期纸角抖动＋干脆掌声；中期掌印更实、桌响变低、翻牌成串；组合成形加入一种主属性墨线与次数标记；后期才出现龙影、旗阵、破阵与全桌翻面。不能开局每掌都全屏爆炸，后期也不能让大招遮住剩余耐力和最后存活牌。

“大卫天龙”是小野喊错的早期招名，雷飞写在包装背面；成熟时叫“大威天龙”，记忆梗保留。目标版第一轮先把它做成达到明确条件的掌势释放表现，避免同时强加12个主动技能。首发建议掌势自动触发为基础、玩家可在辅助设置中保留释放键；后续主动招式只有在核心拍击与八流派稳定后扩展。

完整龙演出约0.8—1.2秒，逻辑持续、可以低特效替代，平均每10秒最多一次大面积演出；大量属性包按行动合并伤害飘字，战报能展开。掌风、火纹、雷纹、风弧、刀痕各有清晰方向和不同材质；范围线先指向目标再播放，不能让玩家分不清哪张被伤到。

声音优先木桌/纸牌：轻拍3个变化、重拍3个、纸边擦响、翻面、收盒、开包、盖章；属性各一层短音，叠加时只保留主声与一层辅声。组合音量不可随段数线性叠到刺耳。操场蝉声、篮球、远处孩子声与店门声提供现实感，战斗音乐不要盖掉手掌。所有口头喊招可关闭，重要提示有字幕，静音仍可理解条件。

## 16. 可访问性、存档与技术约束

支持字号100/115/130%、高对比正文底、色彩与图形双标、震屏0/低/标准、关闭闪白、低粒子、简化龙、字幕、音量分项。键盘焦点可到所有按钮，提供选择目标＋轻拍键/重拍键，辅助重拍仍消耗同规则耐力。提高判定容差不增加系数；设置变化即时预览。

正式存档按版本保存资产、卡品相、装备/兵绑定、预设、地图状态、剧情唯一标记、原盒归还、城市周期、训练快照、种子、结算账本和设置。资产事务先写临时文件、完整验证后替换，保留至少一个上次有效档。异常关闭恢复到最近一致状态，不只保存金币却丢素材。

旧档迁移保留所有169种资产和已有金币，武将旧培养费用按历史公式一次返还，以独立迁移版本防第二次返还；不得重新抢走老玩家资产。已清城保留首通，补已达资格与待看剧情而非重复金币奖励。多出的挂兵、旧重复同城建筑等安全返仓，装备绑定保留。把老玩家送回“回忆序章”，可跳过观看，不强制从新野重打。

离线时间检测负值与大幅异常，不用系统时间变化罚没现有资源。无网络单机以容量封顶和账本去重保证合理恢复，目标不做强联网验证。剧情暂停、战斗暂停、窗口失焦、退出都明确哪些时钟继续；自动训练开关关闭时不生成离线战斗。

### 17.1 三类试玩画像

主动型：一次25分钟，重拍与目标选择熟练；均衡型：一天2次，每次15分钟，挂机与构筑都用；低频型：一天1次，每次10分钟，较常触离线上限。使用同一掉落统计，记录每天资源、首通、配队变化与空等时间。目标均衡型能稳定推进，主动型更快但不跳过关系事件，低频型能由确定补牌完成组合。

## 18. 体验指标、风险与决策顺序

所有数字为目标线，用本地匿名试玩记录或明确同意的测试统计验证；不假定正式产品已达到，不要求接远程分析平台。

| 指标 | 起测目标 | 未达时先改什么 |
|---|---|---|
| 首次理解轻/重拍 | 80%新玩家在5分钟内独立使用 | 输入提示、例桌、目标间距 |
| 失败下一步 | 80%能说出一次具体改动；1—3败买一小助力 | 失败原因、成本、确定接口 |
| 首组合理解 | 前30分钟至少1条两环、前90分钟一条三环 | 卡面语言与获取，不先加新卡 |
| 低星保留 | 中期试玩有至少3种接口被主动留用 | 条件预算、替换预览、兵位限制 |
| 手动的价值 | 同阶段主动冲关明显快于默认自动，玩家愿意手动试 | 重拍条件、目标选择、自动节拍 |
| 回归可行动 | 90%回归在2分钟内看到一项可做提升 | 账本、排序、目标追踪 |
| 等待负担 | 主动15分钟期间没有连续5分钟只能等钱 | 替代训练/桌型、费用、商店路径 |
| 美术一致 | 全图鉴联看无明显异风格跳格；缩略图名字匹配 | 图集标尺与裁剪区，而非多加背景 |
| 稳定与信任 | 资产丢失、重复奖励、无限递归、无法重试为0 | 暂停扩内容，先修事务与状态 |

风险优先级：**P0规则目标与界面不一致、资产迁移丢失、包池保底非法、离线重复账、递归爆炸；P1高星把低星全部替换、唯一最优阵、自动消解手动、城市收入淹没所有玩法、后期空等；P2全卡美术量过大、过量纹理影响阅读、龙演出挡牌、剧情重复打断。**

先验证前30分钟和一个完整流派，再扩全卡与后期。若高星过强，先缩规则叠乘或调整敌阵，不把所有低星也改成大炮；若挂机弱得看不出组合，先测完整轮次和奖励，不立即拉成与手动同强；若图集仍不好看，先统一脸大小、轮廓和色阶，不能只换文件组织。

### 全卡共用的精确边界

- “每轮”统一指每次有效行动，“每拍”指首拍及已规划的完整/加权追加；普通衍生包、属性复制、燃烧均不生成新行动。
- 雷飞增强第一道追加为基准权重＋0.25，不是把已算最终伤害再乘1.25；没有追加才新增权重0.35。张飞只加即时特殊，不加普通、燃烧或回收。
- 荆南校尉在排除自身后统计首拍已有属性种类，条件锁定本行动，不被自己新增的刀反向关闭。
- 韩玄每第3行动的首个有效火命中挂1层燃烧，每秒0.1P、3秒；王甫每行动首火为0.12P、3秒。每目标最多3层，新增替换剩余最短层；满宠×2只对当时有破甲的目标燃烧跳伤生效。
- 易伤与破甲上限均3层、共享6秒；每层易伤全部受伤＋10%，每层破甲只普通受伤＋10%。命中后新增不追溯，白毦兵不复活过期状态。
- 所有范围副包已算源头最终值，不再次吃张飞/易伤；同属性同副目标系数相加，每段每属性最多2个不同副目标，绝不继续扩散。
- 耐力返还所有来源共用floor（开桌耐力×30%）额度，不超过当前上限；有燃烧而耐力耗尽最多等3秒余火，不能回收再开拍。
- 翻牌金币百分比按同一基础金币相加，不加工资、首通或建筑。鲁肃供给桌自身不推进下一次三桌计数；训练失败不当清桌。
