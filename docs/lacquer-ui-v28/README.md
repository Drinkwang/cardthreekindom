# 玄漆鎏金战斗界面 v28

> 历史记录：本页记录2026-10-23的战斗界面精修范围与验收。用户随后确认“统一所有页面外框，内容保留纸面”，当前页面覆盖与后续验收见[全页面外框v29](../lacquer-pages-v29/README.md)；本页的“仅战斗UI”边界保留为当时版本事实。

本轮针对用户反馈的“黑框有横纹、显得粗糙”，继续以[已选B概念图](../art-direction/ui-style-v26/02-lacquer-gold.png)精修真实战斗UI。保留当前布局与玩法，不把概念图作为整张界面背景，也不修改地形或卡牌来制造接近参考图的假象。[v27记录](../lacquer-ui-v27/README.md)保留为历史版本。

## 材质与装饰修正

- 移除原先每2.6像素重复绘制的木纹线，消除上下栏等间距横纹；改用低对比、连续的暖黑漆面渐变。内部渐变纹理启用`use_hdr`保留细微色阶，这不表示游戏开启了HDR显示输出。
- 金框分为外沿高光、暗色凹槽、次级细金线，减少小按钮的重复角花；大栏保留局部回纹，避免密集金线像工程辅助框。
- 卷云换为独立[矢量装饰](../../assets/ui/lacquer_v28/auspicious-cloud.svg)，以194×70绘制；SVG透明度0.25，再乘绘制透明度0.8，最终约0.20，退为漆面暗纹，不接收输入。
- 返回休息按钮与上阵竖旗改为深朱漆底、金色细边和轻微高光，保留按钮悬停、按下、焦点与禁用状态。
- 底栏状态正文由13号增至14号，使用浅象牙色，提高深底可读性。

## 不变的边界

- 底栏112像素、上阵卡面88像素、小地图220×96像素，上下各留8像素；满队横向滚动与44像素带兵头像保持原样。
- 纸牌卡面、人物插画、21城背景与近景地表不变；不调整卡牌位置、世界坐标、默认视野或玩法数值。
- 小地图不增加标题、图例或收起入口；装饰不拦截鼠标，边缘导航、小地图拖动、缩放和战场拍击仍走原有交互路径。
- 战斗期间仍不能换将、装兵或改装备，返回休息后才能整备。
- 本轮精修范围是战斗UI。休息整备首页及商店、构筑、技能、基建继续保留纸面风格；不宣称已将全部菜单换为深漆主题。

## 横纹专项实测

使用实际GPU渲染帧，在1倍、2倍像素比例下抽样96列漆面，比较相邻行亮度跳变。重复横线会产生连续的大幅跳变；本项阈值为1.5/255。

| 版本 | 像素比例 | 相邻行跳变峰值的列中位数 | 超过1.5/255的采样比例 |
| --- | --- | --- | --- |
| v27基线 | 1倍 | 5.281/255 | 72.091% |
| v27基线 | 2倍 | 4.281/255 | 48.729% |
| v28平滑漆面 | 1倍 | 0.715/255 | 0% |
| v28平滑漆面 | 2倍 | 0.715/255 | 0% |

v28两种比例的最大列峰值也均为0.715/255。[基线日志](../shots/lacquer-ui-v28/baseline.log)与[修正后日志](../shots/lacquer-ui-v28/skin.log)记录上述数值。该指标只用于检验横纹根因是否消除，不是AA美术评级，也不能换算为“99%相似度”。整体完成度仍需结合参考图与真实窗口检查。
