# 升级页美术与实装 · v2.1

2026-10-09，Godot 4.7.1。

升级页从文字技能树改为「练掌堂」。拍力、拍速、时长作为三张首屏插画卡，直接展示当前值与下一级的实际值；下方九项进阶修炼按自动经营、武将协力、翻牌收成分组。结算区持续保留「再来一轮」。

## 美术

三张插画由 Codex 内置 ImageGen 生成并接入 Godot 的 TextureRect。暖纸、深褐墨线、朱红、青绿和赭黄与现有古代三国卡牌保持一致。拍力用掌风翻牌，拍速用连拍动势，时长用古代水漏。没有现代人物、腕表或学校元素。

## 实装

- 核心卡显示轻拍伤害、轻拍间隔、每秒拍数和下一轮时长。预览使用当前牌组、武将、装备与建筑的实际公式，不将升级倍率直接乘在所有伤害上。
- 购买按钮接入原有 GameState.buy_upgrade，显示实际金币费用、缺口、尚未解锁、一次学会和满级状态。前置提示使用界面的同一组技能名称。
- 购买后实时刷新数值、费用和金币，保留所选技能、卡片节点及滚动位置。插画可点击选择，金币按钮负责购买。
- 时长卡明确标注延长时间从下一轮生效，不增加已经开始的轮长。金币和升级继续使用原有存档。
- 本轮保留12项升级的原有价格、等级上限、解锁门槛与效果。进阶经营从新野桌次和前置技能逐步开放。
- 小窗口缩短插画展示高度，首屏仍可购买三项核心升级。滚动条提供明确的下方内容入口，底部战果与再来一轮持续可见。

主要实现位于 scripts/upgrade_view.gd、scripts/home_view.gd 和 scripts/autoload/game_state.gd 的 upgrade_preview。
