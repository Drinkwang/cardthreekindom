## 设计

旧木桌上铺一张米黄修炼图，朱红掌印是起点。左侧约七成为技能网络，右侧只展示选中技能的效果与升级价格。节点上仅保留名称、等级和状态，避免把原列表的说明文字全部搬进图中。

网图使用现有八个技能：拍力、耐力、携带位、暴击、装备槽、武将带兵、财路、挂机效率。连线沿用现有前置规则；掌印起点仅作为视觉入口，不新增技能消费。携带位与装备槽共同连接武将带兵，体现跨支汇合。

- 已学会：朱印与实线。
- 可升级：纸签与赭金标记。
- 未解锁：淡墨图案、小锁与虚线。
- 当前选中：朱红双圈；详细数值和唯一升级按钮集中右侧。

底部继续显示宛城未通关、重新挑战、换地图；升级后仍能直接重试。上方保留返回大本营。图中等级、金币与状态是构图示例。
