## 当前实现

- 每座城只绘制一张完整背景，不再按分区摆建筑，也不循环拼地砖。桥、水道、围墙、台阶、码头与场内建筑不再由城内渲染器绘制。
- 新运行资源在`assets/art_v21/`：石地、土地各有横版1717×916和方版1254×1254。按真实世界宽高比选图，等比覆盖裁切，不压扁建筑或横向拉伸地面。
- 颜色采用与现有宣纸UI相邻的暖灰、浅赭、低饱和草木与柔和笔触；没有把概念图中的AI文字、卡牌或假UI贴进游戏。现有真实UI、卡面、按钮布局和字体保留。
- 21城共用两类场地、四张构图资源，结合轻微色调与整图镜像作区分；不是21张独占手绘地图，也不再靠建筑组合区分城市。
- 主图、小地图共用`DistrictArt.draw_background`和同一城池配置。背景只做CanvasItem绘制，没有新增鼠标拦截控件或碰撞体。

保留原世界尺寸、分区、敌牌坐标、默认镜头、RTS输入、判定、收益与存档。`district_art.gd`移除本轮弃用的v17图集拆分、逐区主副景与镜像地砖铺排逻辑；旧图与旧参考保留为历史文件，不做无关删除。

## 视觉边界

边景属于整城外沿，默认镜头聚焦首个未清分区，未必同时看见四角；这是可以继续平移的大地图，不把屏幕四角装饰固定在镜头上。某些比例覆盖裁切会减少边缘草木，优先保持场地连贯与卡牌区域干净。

背景是位图，默认放大及最大放大时细节会变软；石板仍有绘制的接缝和细纹，但不再出现图块拼接线。首轮实机石板过大，已细化石地素材并刷新最终验证。地面的低对比变化不是实际地形高差。外围草木是绘画，不是碰撞体；原生交互验证仍单独执行，不把背景观感当作鼠标逻辑证明。
