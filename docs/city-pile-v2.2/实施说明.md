# 城池牌堆与范围拍击 · v2.2

2026-10-09，Godot 4.7.1。

玩法已改为“一座城池，一堆卡牌”。新野开局一次铺出21张牌，总厚度304；原有五段同时存在于场地中。玩家以小圆圈瞄准，左键按下立即拍击覆盖到的牌，升级范围可以让一掌覆盖更多牌。圆圈高亮会显示当前覆盖张数。

## 操作

| 输入 | 实际行为 |
| --- | --- |
| 左键单击 | 圆圈覆盖的存活卡牌各承受一次轻拍，多目标共享一掌和一次冷却 |
| 鼠标滚轮 | 以鼠标所在位置为锚放大或缩小镜头 |
| 中键按住拖动 | 平移镜头；释放后停止平移 |
| 右上方 − / + | 缩小或放大视野 |
| 右上方归中 | 恢复100%镜头和居中位置 |

镜头支持65%—240%。圆圈与卡牌同步缩放，世界范围始终相同。命中按圆与旋转牌矩形相交计算，因此圈边碰到牌边或牌角也能命中，包括牌堆中被遮挡的牌。已翻牌不再命中；拍空不占拍数或冷却。鼠标移动和释放左键不会再扫牌或追加拍击。

## 范围升级

范围与拍力、拍速、时长组成四项核心升级，使用新生成的扩圈插画。13项升级均接入原有购买和保存流程。

| 参数 | 值 |
| --- | --- |
| 初始世界半径 | 34 |
| 每级增量 | +6 |
| 首次费用 | 24金币 |
| 费用增长 | 每级×1.22，按原升级费用规则取整 |
| 等级上限 | 20 |
| 最高半径 | 154 |
| 首级覆盖面积提升 | 约38.4%，实际命中张数取决于位置和牌堆 |

范围升级立即生效，下一次有效单击使用新的半径；时长升级仍从下一轮生效。界面显示半径、直径、面积提升、金币缺口和满级状态，购买时保留卡片与滚动位置。

## 城池进度与收益

- 原有各段厚度与牌种保留，新野五段总厚度为14+28+48+82+132=304。进入挑战时，一次铺出所有未完成段的牌。
- 清掉某段只兑现该段收益，剩余牌保持位置。整堆全部拍完才重新铺牌，不重置镜头、轮时长或收入。
- 连续已完成段推进永久城池进度。先拍末段不会跳过前面阶段，也不会提前获得唯一奖励。
- 时间到或回营保留金币、升级和连续已完成段。下一轮从该检查点继续，未完成段的厚度重置。
- 原有首通将牌、建筑、城池和亲和奖励仍只发一次；重复城堆继续提供普通收益。
- 自动练习只练已完成的城池部分，离线模拟使用相同的牌堆与清段收益规则。

基础每轮30秒、初始0.6秒一次拍击继续保留。回营购买后可继续本轮或再来一轮。
