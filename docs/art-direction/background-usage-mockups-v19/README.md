## 如何使用这些参考

- 对比整体画风、背景密度、卡牌是否突出、建筑是否属于同一空间。
- 这不是像素级UI还原：生成器仍会改变部分字形、卡牌尺度、栏高与位置。原提示词要求锁定并不代表最终图已经逐像素一致。
- 便于横向对比，四张沿用新野截图的数值、3张敌牌及5区标记示意；并非夏口、夷陵、沅陵的真实分区数、敌牌或关卡状态。
- 小地图缩略图、视野框和城市字样是视觉示意，不能用于验证摄像机坐标或鼠标交互。
- 最终接入时仍需用原生UI叠层和真实地图尺寸验证；不能直接把整张合成图作为游戏界面贴上去。
