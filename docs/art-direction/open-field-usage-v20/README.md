## 本次验收方向

- 中央是连续、平整、低对比、看起来可自由移动的地面，不画窄路、孤立平台或高差。
- 景物只在最外侧和角落点缀；四向留出宽阔开口，不用围墙、栏杆或连续植被围成盒子。
- 移除桥、码头、水道、池塘、门楼、阶梯和伸入场内的建筑，避免视觉上像碰撞障碍。
- 沿用现有UI结构，场上3张卡，底栏1肖像＋3空位。生成图的文字、比例及小地图仍可能漂移，不是逐像素复原。

提示词中的中央85%与外围5–8%是构图目标，未进行精确像素面积测量。地面细纹仍有一定密度，可在定稿时继续压低对比。

**这里只修正视觉方向，没有验证或修改实际鼠标输入、碰撞或镜头逻辑。** 不把概念图当作“鼠标问题已修复”的证据，也没有运行Godot测试。确认画面方向后，接入仍需按真实地图尺寸和可操作区域验证。
