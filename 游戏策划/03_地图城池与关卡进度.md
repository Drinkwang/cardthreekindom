# 03｜地图、城池与关卡进度

状态：当前基线｜2026-10-18。

## MAP-01｜21城与分区

游戏有21座城，按魏、蜀、吴、群雄四条路线连接；新野为起点。每城有固定数量分区：新野5区，城池2—3为6区，4—8为8区，9—14为10区，之后为12区。分区不是连续桌次：它们是同一张大地图里的地理区域。

玩家能看到全部未征服区，并可任意选择先拍哪一区。小地图显示场地、敌牌位置和视野框；分区有足够空间时才显示区号与难度，已征服区不再显示敌牌。战斗和巡城均不显示宝箱、任务NPC或事件标记。

## MAP-02｜征服与重开

| 状态 | 能否进入战斗 | 生成什么 |
| --- | --- | --- |
| 未解锁城 | 否 | 无 |
| 已解锁、未全清城 | 是 | 仅未征服区的敌牌；事件隐藏且不可交互 |
| 已全清城 | 否 | 无敌牌；可巡城 |

每个分区一经征服便永久保存，重开同城时不重刷。未征服区的残余HP不保存。全城征服后不允许“再拍此城”或练习刷资源。

每征服一区，为该城开放1个基建位；新野首次征服任一区赠B06农田与B08水井。基建装配在休息期进行，不在拍卡地图中开启，也不恢复自动产金。

## MAP-03｜巡城

全清城在舆图显示“巡城”。当前巡城用于查看已经征服的城池场地：

- 没有敌牌、倒计时、伤害、经验、自动结算或后台产金。
- 镜头、缩放和小地图仍可使用。
- 宝箱和任务不显示，也不能接取、开启、兑换或领奖；事件数据保留，不为任务重新生成敌人。

## MAP-04｜视野

原截图中的400%被定义为默认视野，因此界面显示为 **0%**。大于默认值显示正百分比，缩小显示负百分比；“回目标区”按钮恢复0%并定位当前未清分区。这只是显示口径变化，不改变拍击半径或世界坐标。滚轮以指针位置缩放，工具栏加减以视野中心缩放；两者都不把拍击光标移到缩放锚点。

小地图位于底部栏右侧，常驻尺寸220×96，不设标题、印章或题签带。整个底栏由上一版140压至112像素，主地图再增加28像素高度（相较最初约164像素底栏累计增加52像素）；保留88像素上阵卡面。底栏上下各留8像素，默认卡牌和小地图垂直居中、不压上边线；底部8像素空白处仍可边缘滚屏，实际横滚条优先操作卡槽。保留敌牌位置与视野框；分区格高不足34像素或宽不足42像素时省去文字题签，避免遮住红点，主地图仍显示分区信息。不显示“卡牌／视野”图例，没有收起按钮或M键折叠。

城池采用整张开放平地背景，中央及四向为同一平面的连续路面，少量草木只在整城外围点景；不再逐分区摆建筑或码头，也不画桥、水道、围墙和台阶来切断通路。石地、土地各有横版和方版，按世界比例等比覆盖裁切；21城通过地面类型、轻微色调及整图镜像区分，不宣称21张独占场景。主图和小地图共用绘制，5区与12区沿用原分区、敌牌及存档几何。素材复用与视觉边界见[开放平地实装](../docs/open-field-v21/README.md)。
