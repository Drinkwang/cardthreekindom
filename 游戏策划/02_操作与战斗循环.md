# 02｜手拍战斗、成长与地图事件

状态：当前基线｜2026-10-18。

## BATTLE-01｜一次手拍

玩家在未征服的城池中按鼠标左键。掌心圆形范围内的所有存活敌牌各受一次轻拍伤害，这批目标共用一次冷却和一次“手拍”计数；本掌拍翻至少一张敌牌才获得一次经验，只打伤没有金币或经验。

| 初始参数 | 当前值 | 改法 |
| --- | ---: | --- |
| 轮长 | 30秒 | `UPGRADE-stamina`每级 +2秒 |
| 轻拍冷却 | 0.6秒 | `UPGRADE-speed`每级频率 ×1.08 |
| 范围半径 | 40 | `UPGRADE-radius`每级 +6 |
| 基础伤害 | `1 + 队伍战力` | `UPGRADE-power`每级 ×1.12 |
| 单人开局伤害 | `1 + 0.3 = 1.3` | 新局仅主角I01，不附送士兵、武将或卡包 |
| 拍翻金币 | 敌牌最大HP ×`(0.45 + 0.12)`×财路倍率 | 手动拍翻时一次发放，伤害过程不支付 |
| 首翻奖励 | 8金币 | 第一次手动拍翻敌牌时额外发放一次 |

玩家不能按住鼠标自动出掌。地图导航采用RTS式操作：中键或空格+左键拖图，滚轮以鼠标所指世界位置为锚点缩放；拖图跨越上下HUD仍持续，松开、失焦或打开覆盖页立即取消。拖图期间不拍牌，也不触发HUD按钮或滚轮缩放。

真实窗口四边各16像素为滚屏外圈，包括上下HUD的装饰留白；地图与HUD之间的内部接缝不触发滚屏。移入即滚动并显示方向箭头，移出立即停止，没有惯性；真实按钮、上阵槽和小地图不触发。优先级为拖图、同帧缩放、边缘滚屏。

小地图在底栏右侧常驻220×148，没有“卡牌 / 视野”图例、收起按钮或M键折叠。重拍/自动拍的旧接口不属于当前玩家操作。

## BATTLE-02｜经验、等级与技能点

每次手拍拍翻至少一张敌牌时：

- 玩家获得 `1` 点经验；每位**上阵武将**各获得 `1` 点经验。范围和手动触发的追击翻多牌共用本次成长；金币仍逐牌结算。士兵与固定主角不走武将经验。
- 只打伤、反复点击已翻牌或冷却中的输入均不发成长；等待燃烧击倒也不发金币、经验或首翻奖励。连击与构筑触发次数仍按有效命中积累，属于本轮战斗状态。
- 玩家升下一级所需经验为 `20 + 10 × (当前玩家等级 - 1)`；升级后获得 `1` 技能点。
- 武将升下一级所需经验为 `10 + 5 × (当前武将等级 - 1)`；等级上限20。
- 武将每升1级，使该武将自身基础战力 ×`1.08`。品相倍率仍独立相乘。
- 玩家经验不会由等待、镜头移动、巡城、护卫位移或建筑获得。

## BATTLE-03｜敌牌、分区与结束

每座城同时摆放所有未征服分区的敌牌。玩家可从低难度或高难度区自由开始。某区敌牌全被拍倒时，该区永久征服；本轮可以继续拍其他未征服区。

轮长归零或点击“返回休息”时，未征服区的残余HP丢弃，已经获得的金币、经验和已征服分区保留。全城征服会立即结束本轮。已征服分区和已全清城不会再生成敌牌。

## EVENT-01｜事件总则（暂停展示的规格）

当前战斗与巡城均隐藏事件卡、小地图事件标记和护卫目标，并跳过事件命中；玩家不能接取任务、开启宝箱、兑换或领奖。事件不是当前可获取金币、经验、卡牌或军需的入口。

以下保留底层已实现的规则与数据，供以后明确恢复或改写，不能据此判断当前界面已经开放。底层每座城创建固定位置的事件牌；事件不计入敌牌数组、不受伤、不提供普通拍击金币。事件状态仍写入新档，奖励保持一次性限制。

| 事件 | 出现位置 | 奖励 | 关键限制 |
| --- | --- | --- | --- |
| 宝箱 | 每城第0区上方 | 军需 ×1 | 拍一下领取；不重复 |
| 限时剿敌 | 每城第0区上方 | 玩家经验 `20 + 城池编号×5` | 20秒内手拍指定士兵2张 |
| 军需兑换 | 每城第0区上方 | 装备：新野E02、第二城E03、之后E04 | 消耗自由库存S01×1和军需×1 |
| 护卫 | 第二城起，第0区下方 | 金币 `30 + 城池编号×10` | 无HP；只能用手拍位移到终点 |

保留的事件集合为宝箱与三类任务；新野的配置没有护卫事件。当前四类事件全部暂停展示与玩家交互。

## EVENT-02｜限时剿敌（暂停展示的规格）

点击剿敌卡接任务。任务锁定该城敌军中的第一种士兵，20秒内击倒2张指定牌即可变为“可领奖”；再次点任务卡结算经验。计时结束、回到休息期或指定敌人已经不够时，任务失败或过期；不会为了任务重新刷敌。

清城前刚达标但未领奖时，底层会保留“可领奖”状态；当前巡城也隐藏事件，因此没有领取入口。

## EVENT-03｜护卫（暂停展示的规格）

护卫NPC是一张地图卡，不是敌人：没有HP、不会受伤、不会吃范围伤害、不会提供经验或普通击倒金币。第一次拍到NPC会接取任务，并按落掌方向移动80世界单位；需要持续手拍把NPC送入终点55单位范围。每次移动消耗同一次手拍冷却，不能连点加速。完成时只发任务定义的金币。
