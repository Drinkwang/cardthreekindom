# 07｜界面流程与交互

状态：当前基线｜2026-10-17。

启动直接进入游戏：新游戏进入新野牌桌，可用当前版本存档则进入休息期继续整备。游戏内不再打开旧主菜单，也没有“返回主界面”或封面页面出口。

## UI-01｜战斗界面

战斗中只服务于拍击：城池世界、小地图、缩放、区域信息、金币/轮次、上阵只读条和“返回休息”。商店、构筑、技能、基建、地图切换和卡池替换均在本轮结束后开放；任何整备入口都不能在拍卡时直接打开页面。

战斗与巡城均不显示宝箱、任务NPC、护卫目标或小地图事件标记。隐藏事件跳过命中，不会截走敌牌拍击，也不能接取、开启、兑换或领奖。事件规则与数据仍保留，详见[02 暂停展示的事件规格](02_操作与战斗循环.md#event-01事件总则暂停展示的规格)。

小地图放在底部栏右侧，常驻尺寸220×96；不设“地图”标题、印章或题签带。整个底栏高度112（上一版140，最初约164），本次释放28像素给主地图；卡槽滚动区域96像素，保留88像素卡面。底栏上下各留8像素，卡牌和小地图不压上边线；默认卡牌垂直居中，满队时给8像素横滚条留位，装兵信息在44像素高头像侧边显示。底部8像素空白继续支持边缘滚屏，悬停实际横滚条只操作卡槽。密集地图省去分区文字题签，只保留分区边界、真实敌牌红点与视野框，主地图分区信息不变。不显示“卡牌／视野”图例，没有收起按钮或M键折叠。上阵竖旗按文字实际字高留出空间。

地形v26为21城分别接入独立背景与近景地表，主图和小地图读取相同城池资源；不改变上述UI尺寸、卡牌、镜头默认值或鼠标命中规则。用户已从[纸墨、玄漆鎏金、玉白山水三套UI概念图](../docs/art-direction/ui-style-v26/README.md)中选择B，战斗界面沿用v28无周期横纹的平滑漆面、分层金边、低对比卷云与深朱漆按钮；按[全页面玄漆鎏金外框v29](../docs/lacquer-pages-v29/README.md)将同套外壳延续到休息、商店、构筑、技能、基建、舆图和开卡页面，深底标题与统计改为浅字，正文仍保留纸面深墨，纸牌和21城地形保持原样。概念图本身不是游戏实机截图，真实换肤另做原生验收，不把横纹指标称为AA评级或相似度评分。

## UI-02｜休息期

主动结束本轮、时间结束或全城征服后回到休息期，进入大本营。营地首页有2×2四个入口：

| 入口 | 可做的事 |
| --- | --- |
| 商店 | 买卡包、招降、合成、查看收藏 |
| 构筑 | 上阵、卸下、配装备、带兵、查看武将等级经验 |
| 技能 | 查看玩家等级/经验/技能点并加点 |
| 基建 | 在已征服分区开放的位置装配、移动、卸下建筑，查看组合与功能加成 |

进入休息期后不会自动重新铺桌；玩家完成整备，再主动继续出战。剧情、札记、教程条、旧主菜单、返回主界面、自动收益开关和“再拍新野”入口均已移除。基建在线、离线与组合自动产金继续暂停，详见[06 基建与暂停收益](06_基建自动练习与离线收益.md)。

## UI-03｜信息口径

- 上一版+50%的视野改为默认0%，内部默认倍率6.0；开局和“回目标区”均使用此倍率，实际缩放上下限不变。
- 武将详情显示等级、经验、升下一级需要的经验和成长倍率。
- 技能按钮显示需要的技能点；金币再多也不能代替技能点。
- 巡城显示“巡城”而非倒计时，且不显示敌牌、宝箱或任务，也没有事件交互入口。

## UI-04｜升级修炼图

升级页为九个圆形节点＋前置箭头＋右侧详情。点节点不消费，右侧唯一按钮消耗1技能点。真实前置尚未满足时仍可选择查看，但不能购买。详见[16 升级修炼图与分区美术](16_升级修炼图与分区美术.md)。

修炼节点的名称纸签按字高留足高度；构筑页的按钮与说明文字按实际可用宽高排版，避免文字超出纸框。1280×720和1280×800原生窗口对照放在[本轮布局截图](../docs/ui-layout-v13.1/)。
