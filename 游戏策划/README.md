## 当前版本的硬规则

- 启动直接进入游戏：新游戏进入新野牌桌，可用当前版本存档则进入休息期；游戏内不再提供旧主菜单或“返回主界面”出口。
- 新游戏只有主角I01，不附送卡包、士兵或武将；初始轻拍伤害1.3。
- 当前可玩流程的金币只在玩家手动拍翻敌牌时一次结算；只打伤没有金币或经验。
- 一掌拍翻至少一张敌牌，玩家与每位上阵武将各得1经验；范围与追击翻多牌共用本次成长。玩家升级给技能点，技能只消耗技能点，不消耗金币。
- 已征服分区不再刷敌。全城征服后可“巡城”查看场地，不会出现敌牌或倒计时。
- 战斗与巡城均隐藏宝箱和任务，不显示事件卡、小地图标记或事件命中入口，不能接取、开启或领取。原宝箱、剿敌、兑换、护卫规则与数据保留为暂停展示的规格。
- 战斗时只保留拍击、镜头、小地图和“返回休息”；商店、构筑、技能、基建、地图切换和卡池替换均在休息期。休息营地恢复2×2四入口，整备后由玩家主动继续出战。
- 每征服一区开放该城1个基建位；新野首个清区赠农田与水井。建筑恢复卡包获取、装配、移动、卸下、组合收藏及功能加成；在线、离线与组合自动产金仍为0。
- 小地图放在底部栏右侧，常驻尺寸220×148；不显示“卡牌 / 视野”图例，没有收起按钮或M键折叠。
- 剧情、札记和教学提示已从当前流程移除，后续由你重新撰写。
- 当前版本只使用 `user://save_paan_adventure.json`，不读取、迁移或补偿旧存档。
